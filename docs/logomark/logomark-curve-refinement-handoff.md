## 2. 選択コンセプト: 「紋 — Modern Kamon」

### 2.1 コンセプト概要

6人の専門家（幾何学ロゴ研究、数理基盤、モノグラム融合、漢字文化記号学、スケーラビリティ技術、ブランド設計言語）による並列リサーチの結果、5/6の専門家が支持した方向性。

**核心アイデア**: 漢字「工」(craft/engineering) を超楕円フレーム内に収めた現代の個人紋。C弧が工を半包含する構造。

### 2.2 構造

```
紋 Modern Kamon の構造:

  ╭━━━━━━━━━━━╮
  ┃  ═══════  ┃ ═══   ← C弧の上部水平 = 工の上横画 = T のクロスバー
  ┃     ║     ┃       ← 工の縦画 = T のステム（白銀比位置）
  ┃     ║     ╯       ← 超楕円弧 + 30°ターミナルカット（開口 = C の暗示）
  ┃  ═══════  ┃ ═══   ← C弧の下部水平 = 工の下横画
  ╰━━━━━━━━━━━╯

2要素で構成:
  1. C弧フレーム（上横画 + 左超楕円弧 + 下横画）— 1つの closed path
  2. 縦画（独立した矩形）
```

### 2.3 意味の層（Meaning Layers）

| Layer | 読み | 対象 |
|-------|------|------|
| 1 | 幾何学的シンボル | 文化に依存しない美 |
| 2 | TC（イニシャル） | 西洋人の目: C弧 + T(上横画+縦画) |
| 3 | 工（たくみ） | 日本語読者: 三画構造 |
| 4 | 工芸 = 工学 × 芸術 | 深層: ソフトウェア × 写真 |
| 5 | 現代の個人紋 | 1000年の家紋伝統への接続 |

### 2.4 ユーザーの不満点（重要な文脈）

- 現行マーク（リデザイン前）の「T+C+工の単純な重ね合わせ」を否定
- パーツごとの1:1マッピング（「T=ここ、C=ここ」）は機械的すぎる
- 「認知の層」による自然な多義性を求めている
- **工の上半分 = T は数学的事実** → T を別途デザインする必要なし

## 3. 数学的根拠の全体系

### 3.1 ロゴタイプで確立した設計言語（マークに継承）

| 原則 | ロゴタイプでの適用 | マークへの適用 |
|------|------------------|--------------|
| **黄金比 φ = 1.618** | H クロスバー位置 H×(1-1/φ) | 左右余白比 18:11 ≈ φ |
| **Fibonacci** | 文字幅比 21:13:5, 基本単位 48UPM | アーム幅 12u |
| **超楕円 n≈2.5** | C, B, U のカーブ | C弧の左側カーブ |
| **30° ターミナル** | C, T の端処理 | 開口部の上下端カット |
| **ink trap** | B ウエスト, K ジャンクション | 未実装（次フェーズ候補） |
| **fill ベース** | アウトラインパス | 同一 |

### 3.2 白銀比 δ = 1+√2 の導入（マーク独自）

**縦画位置の決定に使用。**

日本建築（法隆寺、金閣寺）の基本比率。畳の比率 1:√2 と関連。
漢字「工」と白銀比の文化的整合 = 東西融合の数学的表現。

**計算:**
```
内部空間: x=22（C弧内壁）→ x=63（30°カット内端）= 幅 41 units
白銀比分割: 41 × √2/(1+√2) = 41 × 0.5858 = 24.02
分割点: x = 22 + 24.02 = 46.02 ≈ 46（縦画中心）

縦画: x = 40→52（幅12、中心 x=46）

左余白: 40 - 22 = 18
右余白: 63 - 52 = 11
18 : 11 = 1.636 ≈ φ (1.618) — 誤差 1.1%

→ 白銀比で分割すると余白が黄金比になる = φ × δ の数学的共鳴
→ 西洋の黄金比 × 日本の白銀比 = integrated perspective
```

### 3.3 超楕円 n=2.5 のベジェ近似

**現行の制御点計算:**
```
|x/a|^n + |y/b|^n = 1,  n = 2.5

制御点オフセット係数: k = 0.688 × radius
（通常の楕円/円: k = 0.5523 × radius）

45°方向で円より 7.2% 外側に膨らむ
→ 「四角の意図と曲線の流れの間の静的緊張」= quiet tension の幾何学的定義
```

### 3.4 30° ターミナルカット

```
tan(30°) = 1/√3 = 0.5774

開口部カット:
  上端: (70, 10) → (63, 22)
  下端: (70, 70) → (63, 58)
  dx = 7, dy = 12
  angle = atan(7/12) = 30.24° ≈ 30° ✓

30° は √3 / 正三角形 / Vesica Piscis と同じ角度体系
→ ロゴタイプの C, T ターミナルと統一
```

### 3.5 数理体系の統一性（重要な発見）

```
φ = (1+√5)/2
 ├── Fibonacci数列: φ = lim F(n+1)/F(n)
 ├── 黄金角: 360°/φ² = 137.508°
 ├── √5: φ = (1+√5)/2
 ├── 正五角形: 対角線/辺 = φ
 │    └── 角度系: 36°/72°/108°
 └── 30° ターミナル ← √3 / Vesica Piscis 経由

δ = 1+√2（白銀比）
 ├── 畳の比率 1:√2
 ├── DIN A紙サイズ
 └── 日本建築の基本比率

φ × δ の共鳴: 白銀比分割 → 余白が黄金比
```

## 5. 現行の問題点: カーブと角

### 5.1 ユーザーのフィードバック

> 「カーブや角が美しくない」

### 5.2 問題の分析

#### 問題 A: 超楕円カーブの精度
- 現行は k=0.688 の単一ベジェ近似
- 90°弧を1つの3次ベジェで近似しているため、弧の中間部分の精度が低い
- 真の超楕円 n=2.5 と比較して、特に30°〜60°の範囲で誤差がある可能性
- **研究課題**: 2分割ベジェ（45°ごと）や4分割ベジェでの精度向上

#### 問題 B: 直線→曲線の遷移（接線連続性）
- 上横画の水平直線 (y=10) から C弧カーブへの遷移点 (40, 10)
- 現行: `L40 10 C19.4 10...` — CP1 が (19.4, 10) で y=10 上にあるため、接線連続（G1連続）は保たれている
- しかし曲率連続（G2連続）は保証されていない
- **研究課題**: G2連続（曲率が滑らかに変化）のための制御点調整

#### 問題 C: 直角コーナー（縦画、横画右端）
- 縦画の4角: 完全な直角（90°シャープコーナー）
- 横画右端: 30°カットで斜めだが、頂点はシャープ
- **研究課題**: 超楕円的角丸（n=2.5 ベース）の適用、角丸半径の決定

#### 問題 D: 30°ターミナルカットの処理
- 開口部の30°カット端 (63, 22) と (63, 58) が鋭角のシャープポイント
- (70, 10) から (63, 22) への直線が急すぎる可能性
- **研究課題**: カット端の丸め処理、カットの角度微調整

#### 問題 E: 弧と横画の厚みの視覚的不均一
- C弧の最左部 (x=10→22) での厚み = 12（水平方向）
- 横画部分 (y=10→22) での厚み = 12（垂直方向）
- 弧の斜め部分での厚みは √(12²+0²) 〜 √(12²+12²) の範囲で変化
- **研究課題**: 弧部分の厚み補正（等幅弧 vs 自然な太さ変化）

#### 問題 F: 内弧と外弧の中心不一致
- 外弧の中心: 超楕円的には (40, 40)
- 内弧の中心: 同じく (40, 40) だが半径が異なる (R=30 vs r=18)
- 同心超楕円のオフセットは真の等距離オフセットではない
- **研究課題**: 等距離オフセット曲線の計算

## 9. 次フェーズの研究課題

### 9.1 カーブの精緻化

1. **超楕円 n=2.5 のベジェ近似精度向上**
   - 1ベジェ/90° → 2ベジェ/90°（45°分割）の効果測定
   - n=2.5 の正確な形状を数値的に計算し、ベジェ近似との誤差を可視化
   - 他のCADソフト/ツールでの超楕円実装事例の調査
   - Piet Hein の超楕円デザイン応用の詳細研究

2. **曲率連続性（G2連続）**
   - 直線→曲線の遷移点での曲率変化を滑らかにする
   - G0（位置連続）→ G1（接線連続）→ G2（曲率連続）の違いの可視化
   - Bézier spline vs B-spline の比較

3. **内弧と外弧の等距離オフセット**
   - 現行の同心超楕円（半径差12）は真の等距離オフセットではない
   - 等距離オフセット曲線の計算方法
   - 弧の斜め部分での厚み変化の補正

### 9.2 角の精緻化

4. **シャープコーナーの処理**
   - 縦画の4角: 直角 → 超楕円的角丸（n=2.5）の適用
   - 30°カット端の角丸処理
