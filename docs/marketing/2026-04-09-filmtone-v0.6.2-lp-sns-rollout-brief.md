# Filmtone v0.6.2 LP / SNS Rollout Brief

## 1. Objective

- Align public LP and SNS with the actual shipped state after `Filmtone Desktop v0.6.2`.
- Keep the message `video-led / Desktop-first / motion-proof-first`.
- Treat Web as `try-first` and Desktop as `finish / export / production`.
- Keep stills as `same-world extension`, not the main narrative.

## 2. Core Message

- Hero line: `Make your videos feel finished fast.`
- Support line: `Try the look in your browser. Finish and export on Desktop.`
- Proof line: `Play it, compare it, finish it.`
- Release line: `Desktop v0.6.2 now live on macOS.`

## 3. LP Rules

- Lead with video finished-feel, not preset count or folder batching.
- Keep `Cross Filter` as the shipped public name.
- Use `Base Looks / Finish Tools / Trim` only as explanatory grammar, not as proof that the full family system is publicly shipped.
- Keep current proof slots live while the shared masters are being replaced:
  - `gradedLookA` stays the first shared-proof slot
  - `gradedLookB` stays the second shared-proof slot

## 4. Shared Proof Asset System

- One asset system feeds both LP and SNS.
- Shared master spec:
  - `H.264 mp4`
  - `24fps`
  - `5-8 sec`
  - silent-legible
  - center-crop safe for LP cards
- Canonical proof sequence:
  1. `raw`
  2. `base look`
  3. `family on / Light`
  4. `final / Strong`
- First-wave priority:
  1. `Cross` shared master
  2. `Glow` shared master
- Current LP asset mapping:
  - `gradedLookA` now uses the blue bokeh graded proof source (`746066 ... graded.mp4`) as the above-the-fold motion proof.
  - `gradedLookB` now uses the hanging practical-lights graded proof source (`6164083 ... graded.mp4`) as the second motion proof.
  - `compare-night-street.mp4` comes from the current macOS compare capture (`flimtone04.MP4`).
  - `compare-daylight-walk.mp4` comes from the current macOS compare capture (`flimtone03.MP4`).
  - `compare-dark-interior.mp4` comes from the current macOS compare capture (`flimtone01.MP4`).

## 6. Guardrails

- Do not make the launch a `v0.6.2` changelog thread.
- Do not return to photo-first / preset-first hero messaging.
- Do not frame Filmtone as a Resolve or Dehancer replacement.
- Do not center Smart Look AI, Windows, RAW, LUT export, or shared URLs.
- Do not present `Mist / Glow / Cross / Texture / Lens / Motion` as if the full public family packaging is already shipped.

## 7. Immediate Next Asset Work

- Keep LP and SNS derived from the same mastered clips; only crop, caption, or end card may change.
- Use the current graded proofs as the first-wave public proof until a stricter `Cross` / `Glow` naming pass is ready.
