# Cafe Cursor Tokyo Instagram Ads Execution Brief

## 1. Overview

- Campaign name: `Cafe Cursor Tokyo | Profile Visits | Carousel | Week 1`
- Goal: `認知拡大`
- Primary action: `プロフィールアクセス`
- Budget: `日額 1,500円`
- Duration: `7日固定`
- Total planned spend: `10,500円`
- Ad format: `既存カルーセル投稿の宣伝`
- Team mode: `Agent Teams`
- Director role: `orchestrator-director 相当の統括役`

## 2. Team Roles

### Orchestrator Director
- 全体KPI、配信状況、変更タイミングを管理する
- Day 2 / 4 / 7 の判断を最終確定する
- 変更は1回につき1要素だけに制限する

### Media Buyer
- 目的は `プロフィールアクセス`
- `複数のアクション` は使わない
- `この広告を停止するまで掲載` は使わない
- `Advantage+ audience` はON
- 配置は自動最適化を基本にする

### Audience Strategist
- 地域: `東京都 / 神奈川県 / 千葉県 / 埼玉県`
- 年齢: `20-39`
- 性別: `すべて`
- 詳細ターゲットは狭くしすぎない
- 入力する場合の補助シグナル:
  - `coffee`
  - `cafe`
  - `coworking`
  - `startup`
  - `creative technology`
  - `design`
  - `photography`
  - `events`

### Creative Strategist
- 既存素材からカルーセル `A/B 2変種` を作る
- 1枚目で `誰の何の場か` が伝わる構図を優先する
- 最終枚でプロフィール遷移の理由を補強する
- 過剰な文字入れはしない

### Copy / Profile Funnel Specialist
- キャプションは `イベント記録` ではなく `ブランド接触`
- Bio、固定投稿、ハイライトで受け皿を作る
- CTAは1つだけに絞る

### Analyst
- 優先指標:
  1. プロフィールアクセス単価
  2. リーチ
  3. スワイプ反応
  4. 保存率
  5. シェア率
  6. フォロー増加

### Campaign / Boost setup
- Action goal: `あなたのプロフィールにアクセスする`
- Audience mode: `Advantage+ オーディエンスを利用`
- Audience name: `CCT_Profile_Week1_Kanto_20to39_All`

- Minimum age: `20`
- Maximum age: `39`
- Gender: `すべて`
- Daily budget: `$10` 相当の画面表示なら `約1,500円/日` に寄せる
- Schedule: `期間を設定`

### Settings to avoid
- `複数のアクション`
- `この広告を停止するまで掲載`
- 初回からの細かい手動配置の固定
- 初回からの過度な興味関心絞り込み

## 4. Profile Funnel Requirements

### Bio
- 1行目で `何のアカウントか`
- 2行目で `誰向けか`
- 3行目で `次に何を見ればよいか`

### Pinned post
- 1本は `Cafe Cursor Tokyo` の受け皿投稿
- 1本は `他イベント実績`
- 1本は `依頼導線 or 連絡方法`

### Highlight
- `Events`
- `Work`
- `About`
- `Contact`

## 5. Day 2 / 4 / 7 Decision Rules

### Day 2
- 明らかに弱い変種があれば停止
- 勝敗未確定なら継続
- コピーと画像順を同時に変えない

### Day 4
- 勝ち変種が見えたら予算はそのままで寄せる
- まだ拮抗なら1枚目だけ差し替えて再学習

### Day 7
- 勝ち訴求あり:
  - 同訴求継続
  - 必要なら `日額 2,000-2,500円` に増額
- 勝ち訴求なし:
  - 1枚目と導入文を再設計
- 認知は出るが反応が浅い:
  - 次回は `リール化` を検討

- `プロフィールアクセス` が選択されている
- `Advantage+ audience` がON
- 地域が `首都圏` で明示されている
- 年齢が `20-39` になっている
- 期間が `7日固定`
- 受け皿プロフィールが更新済み
- カルーセルA/Bのどちらを入れるか明確
