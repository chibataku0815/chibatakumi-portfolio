## 「再現できてない」と感じたとき（読み替え）

ここでやっているのは次の **3つだけ** です。

1. **Remotion が決めたフレーム 0〜209 を、1枚も抜かず PNG にした**（欠番ゼロの検証付き）。  
2. **コードの式**（`getCameraFocusIndex` など）を **表にした**（数値の説明用）。  
3. **Studio と CLI の WebGL を Angle に寄せる**（`remotion.config.ts` の `setChromiumOpenGlRenderer('angle')`）。以前は Studio だけ別バックエンドのときがあり、**同じフレームでも見え方が変わる**ことがありました。

**「再現」していないのではない例**:

- **表の `focusIndex` と、目で見たカメラの位置がピタッと一致しない**  
  → 実カメラは毎フレーム `lerp` で遅れて追従しているので、**ピクセル一致の正は PNG** です（表は論理フォーカス）。
- **CleanShot の録画や別プレーヤの mp4 と並べると違う**  
  → それらは **Remotion の composition フレームと 1:1 ではない**ことが多いです。比較は **Studio のフレーム番号 ↔ `frame_XXXX.png`** で行ってください。

**並べて確認する手順（おすすめ）**:

1. `bun run dev` で Studio を開き、`ThreeRanking` でフレーム（例: 100）を止める。  
2. `bunx remotion still src/index.ts ThreeRanking /tmp/check.png --frame=100 --gl=angle`  
3. `/tmp/check.png` と Studio の見た目を比較（`remotion.config.ts` 適用後は Studio 側も Angle 寄り）。

## Motion grammar（`getCameraFocusIndex` と同一）

定数（`ThreeRanking.tsx`）:

- `introFrames = 18`
- `segmentFrames = 8`
- `moveFrames = 5`（各セグメントの先頭 5 フレームが **move**、残り 3 が **pause**）
- 塔は 20 本（index `0..19`）。`segmentIndex` は `min(19, floor(localFrame / 8))`。

式:

- `localFrame = max(0, frame - introFrames)`
- `segmentFrame = localFrame % segmentFrames`
- `moveT = segmentFrame < moveFrames ? segmentFrame / moveFrames : 1`
- `easedT = Easing.inOut(Easing.cubic)(moveT)`（Remotion）
- `focusIndex = min(19, segmentIndex + easedT)`（カメラフォーカス用の **論理**連続値）
- **nearestTowerIndex** = `round(focusIndex)` を 0..19 にクリップ（overlay の active rank）

**イントロと rise 開始**: `frame < 18` では `localFrame === 0` のため、**frame 0〜17** は同一セグメント先頭相当（タイトル／パネルの fade のみ進行）。**frame 18** も `localFrame === 0`（`frame - 18`）。**frame 19** から `localFrame` が 1 ずつ増え、塔間の **cubic-in-out move** が始まる。

**CameraRig**: 実カメラ位置は `lerp(..., 0.22)` で毎フレーム追従するため、**ピクセル完全一致の再現は各フレームの still** を正とする（本表は論理フォーカスと overlay 数値の SSOT）。

## 列の意味

| 列 | 説明 |
|----|------|
| `frame` | composition フレーム index（SSOT） |
| `localFrame` | `max(0, frame - 18)` |
| `segmentIndex` / `segmentFrame` | 8 フレーム単位の区間インデックスとセグメント内 0..7 |
| `phase` | `move`（5f）または `pause`（3f） |
| `moveT` / `easedT` | 線形移動進捗と cubic-in-out 後 |
| `focusIndex` | 論理カメラフォーカス（小数あり） |
| `nearestTowerIndex` | UI で強調される塔 index |
| `titleOpacity` / `panelOpacity` | `filmtoneFadeIn(frame, 0, 30, 0.7)` および `filmtoneFadeIn(frame, 14, 30, 0.7)` と同一式 |
| `stillFile` | 全フレームキャプチャ時の推奨ファイル名（`frame_0000.png` … `frame_0209.png`） |
