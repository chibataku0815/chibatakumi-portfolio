## Excellence Framework

### 5つのレベル

```
Level 5: Award-Worthy（受賞レベル）
         ↑ 新しい基準を作る、業界に影響を与える
Level 4: Distinctive（差別化）
         ↑ 他にない個性、感情的インパクト
Level 3: Refined（洗練）
         ↑ 細部まで磨かれている、意図が明確
Level 2: Professional（プロフェッショナル）
         ↑ 業界標準を満たす、一貫性がある
Level 1: Functional（機能的）
         ↑ 要件を満たす、エラーがない
```

### 評価次元

1. **Visual Impact**: 見える → 整っている → 美しい → 印象的 → 衝撃的
2. **Motion & Interaction**: わかる → スムーズ → 心地よい → 意味がある → 物語を紡ぐ
3. **Technical Craft**: 動く → 効率的 → 最適化 → 表現を可能にする → 革新
4. **Emotional Resonance**: 邪魔しない → 快適 → 心地よい → 動かす → 忘れられない
5. **Conceptual Clarity**: 何かわかる → 意図わかる → 一貫 → 世界観 → 新視点

## Level 5 の特徴

### Award-Worthy Checklist（6軸評価）

```
□ The "Wow" Test: 初見で「これは違う」と感じるか？
□ The "Only Here" Test: このサイトでしか体験できない瞬間があるか？
□ The "Coherence" Test: すべての要素が同じ言語を話しているか？
□ The "Craft" Test: 404ページまで設計されているか？
□ The "Emotion" Test: 意図した感情が生まれているか？
□ The "Innovation" Test: 何か新しいことをしているか？
```

### Signature Moment

Level 5 に必須の要素。「このサイトでしか体験できない瞬間」の定義。

**テンプレート:**
```markdown
### Signature Moment
[このサイトでしか体験できない瞬間]
← Level 5に必須。これがなければLevel 4止まり。

例: 「作品カードをホバーした瞬間、背景シェーダーが
     その作品の色彩に呼応して微かに脈動する」
```

## Level 5 対応スキル詳細

### 1. art-direction（アートディレクション）

**追加要素:**
- Award-Worthy Reference Library（Active Theory, Locomotive, Resn, etc.）
- Level 5 Mood Design（ムードの「裏切り」と「回収」）
- Level 5 Narrative Techniques（Unexpected Turn, Callback, Easter Egg）
- 6軸 Award-Worthy Checklist
- ケーススタディ: Active Theory

**Level 5 の定義:**
```
Level 3: 色彩理論に基づいた配色、整った構図
Level 5: 「これは違う」という即座の認識
        技術的な驚きと感情的な引き込みが同時
        Signature Moment の確立
```

**Anti-Pattern（避けるべき）:**
```
Generic Patterns (Level 1-2):
- テンプレートのまま
- 「綺麗」だが記憶に残らない

Stagnation Patterns (Level 3-4):
- Level 3 で妥協する
- 「もうこれで十分」と思考停止
```

### 2. motion-design（モーションデザイン）

**追加要素:**
- Award-Worthy Motion Reference Library（Aristide Benoist, Dennis Snellenberg, etc.）
- Level 5 Motion の5要素（ボキャブラリー、オーケストレーション、予想外、沈黙、パフォーマンス）
- Level 5 Stagger Patterns（予測不能な心地よさ）
- Level 5 Transition Anatomy（5段階: 予感 → 収束 → 間 → 展開 → 着地）
- Polyrhythm コンセプト（複リズムの調和）

**Level 5 Stagger Pattern:**
```
Generic Stagger (避ける):
  Element 1: |████        | +0.0s
  Element 2: |  ████      | +0.1s
  Element 3: |    ████    | +0.2s
  → 予測可能、退屈

Level 5 Stagger:
  Element 1: |████            | +0.0s  (主役、長め)
  Element 2: | ██             | +0.05s (素早く追従)
  Element 3: |  ██            | +0.08s (さらに素早く)
  Element 4: |        ████    | +0.4s  (間を置いて)
  → 「呼吸」のリズム、予測不能な心地よさ
```

**Level 5 Transition Anatomy:**
```
Phase 1: 予感 (0-200ms)        - 現在のページ要素が「準備」を始める
Phase 2: 収束 (200-500ms)      - exit point に向かって集まる
Phase 3: 間 (500-700ms)        - 完全な空白、「息を吸う」瞬間
Phase 4: 展開 (700-1200ms)     - entry point から現れる
Phase 5: 着地 (1200-1500ms)    - 最終位置に落ち着く、余韻
```

### 3. webgl-shader（WebGL/シェーダー）

**追加要素:**
- Award-Worthy WebGL Reference Library（Active Theory, Immersive Garden, Bruno Simon, Inigo Quilez）
- Level 5 Shader Techniques（ドメインワーピング、SDF、カスタムノイズ）
- GPU最適化戦略（KTX2圧縮、インスタンシング、プログレッシブローディング）
- Advanced Noise Library（Simplex, Voronoi, Curl）
- Level 5 Quality Checklist（6軸評価）

**Level 5 の定義:**
```
Visual Innovation:
□ 見たことのない視覚表現
□ カスタムノイズアルゴリズム
□ プロシージャル生成の独自性

Technical Excellence:
□ Core Web Vitals 達成（LCP < 2.5s with WebGL）
□ 60fps desktop, 30fps+ mobile 維持
□ GPU最適化（KTX2, インスタンシング）

Conceptual Integration:
- シェーダーが「装飾」ではなく「体験の核」
- パフォーマンスとクオリティの妥協なし
```

**Level 5 Shader Techniques:**

1. **Domain Warping**（Inigo Quilez スタイル）
```glsl
vec2 domainWarp(vec2 p, float time) {
  vec2 q = vec2(fbm(p), fbm(p + vec2(5.2, 1.3)));
  vec2 r = vec2(
    fbm(p + 4.0 * q + vec2(1.7, 9.2) + 0.15 * time),
    fbm(p + 4.0 * q + vec2(8.3, 2.8) + 0.126 * time)
  );
  return fbm(p + 4.0 * r);
}
```

2. **GPU-Optimized Particles**
```tsx
// インスタンシング + Data Texture でGPUシミュレーション
function Level5Particles({ count = 10000 }) {
  const dataTexture = useMemo(() => {
    // GPU-based simulation
    return new THREE.DataTexture(data, size, size, THREE.RGBAFormat, THREE.FloatType)
  }, [count])

  return (
    <instancedMesh args={[undefined, undefined, count]}>
      <customParticleMaterial uDataTexture={dataTexture} />
    </instancedMesh>
  )
}
```

3. **Performance Optimization**
```glsl
// Conditional compilation for performance tiers
#ifdef HIGH_QUALITY
  float noise = fbm(uv * 8.0, 8); // 8 octaves
#else
  float noise = fbm(uv * 4.0, 4); // 4 octaves (mobile)
#endif
```

## 哲学

> **「良い」は敵。「素晴らしい」を目指す。**
>
> Level 3（洗練された）で満足しない。
> Level 4（差別化された）で妥協しない。
> Level 5（受賞レベル）を当然の目標とする。
>
> これは傲慢ではなく、基準の設定。
> 到達できなくても、目指すことで Level 4 に到達する。
> Level 3 を目指すと Level 2 になる。
