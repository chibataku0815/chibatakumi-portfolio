# CJK タイポグラフィの罠と対策

> 作成: 2026-03-10 | 発見契機: Photography ヒーローの "イベントの熱を" が "イベン|トの熱を" に改行

## text-wrap: balance と CJK

### 問題

`text-wrap: balance`（Tailwind の `text-balance`）は行幅を均等化するアルゴリズム。
CJK テキストに適用すると、**文字数を半分に割る**ため不自然な改行が発生する。

```
"イベントの熱を"（7文字）
├─ balance → "イベン" (3) + "トの熱を" (4)  ← 不自然
└─ greedy → "イベントの" (5) + "熱を" (2)    ← 自然（助詞「の」の後）
```

### 対策

**CJK テキストには `text-balance` を使わない。** デフォルトの greedy アルゴリズムが各行を最大限詰めるため、自然な位置で改行する。

## ch 単位 vs em 単位

### 問題

CSS の `ch` 単位は **"0" の文字幅** を基準とする。
CJK 文字は full-width（全角）で **1文字 ≈ 2ch** になる。

```
max-w-[9ch] → 9 × "0"幅 ≈ 4.5 CJK文字分
max-w-[9em] → 9 × font-size ≈ 9 CJK文字分
```

### 対策

CJK テキストの幅制約には **`em` 単位を使う**。1em ≈ 1 CJK文字。

## word-break: auto-phrase

### 概要

`word-break: auto-phrase` は **Chrome 130+**（2024年12月〜）で利用可能な CSS プロパティ。
日本語・中国語・韓国語のフレーズ境界を認識し、自然な位置で改行する。

```css
h1 {
  word-break: auto-phrase; /* Chrome 130+ */
}
```

### ブラウザ対応

| ブラウザ | サポート |
|---------|---------|
| Chrome 130+ | ✅ |
| Edge 130+ | ✅ |
| Safari | ❌（default fallback） |
| Firefox | ❌（default fallback） |

非対応ブラウザでは通常の文字レベル改行にフォールバック。ポートフォリオなど Chrome メインのサイトでは実用的。

## グリッドカラム幅 vs フォントサイズの計算

大きなフォントサイズの CJK テキストでは、**max-w ではなくグリッドカラム幅が実際の制約**になることが多い。

### 計算例

```
コンテナ: max-w-7xl = 1280px
グリッド: 1.08fr / 0.72fr、gap-12 (48px)
左カラム幅: (1280 - 48) × 1.08/1.8 ≈ 739px

フォントサイズ: clamp(2.9rem, 10.2vw, 8.4rem)
  → 1440px viewport: min(146.9px, 134.4px) = 134.4px

1行に入る CJK 文字数: 739 / 134.4 ≈ 5.5文字
→ "イベントの" (5文字) が収まり、"熱を" が次行へ
```

max-w を設定しても、カラム幅が狭ければ効果がない。**先にカラム幅でのレイアウトを確認すること。**
