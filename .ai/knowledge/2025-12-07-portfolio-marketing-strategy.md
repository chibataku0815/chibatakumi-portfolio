# Portfolio Marketing Strategy Definition

**作成日:** 2025-12-07
**対象:** 千葉拓海ポートフォリオサイト
**ステータス:** 初期定義完了

---

## 0. ビジネスゴール（この戦略の目的）

### 達成したい具体的成果

```
【ビジネス目標】
├─ より良い案件を獲得する
│   - 高単価・高裁量の案件
│   - クリエイティブの本質に関われるプロジェクト
│   - 長期的なパートナーシップ
│
└─ 案件にアサインされる（指名される）
    - 「この人に任せたい」と選ばれる
    - 紹介・リピートが発生する
    - 価格ではなく価値で選ばれる
```

### 目的と手段の関係

```
【目的】良い案件獲得 / 指名アサイン
            ↑
【手段】「統合クリエイティブ・パートナー」として認知させる
            ↑
【実行】ポートフォリオサイトのデザイン・コピー・CTA
```

### 成功指標（定性）

| 指標 | 現状 | 目標状態 |
|------|------|---------|
| 案件の質 | - | クリエイティブ本質に関われる案件が増加 |
| 指名率 | - | 「あなたに頼みたい」という相談が主流に |
| 単価 | - | 価値ベースの交渉が可能に |
| 紹介 | - | 既存クライアントからの紹介が発生 |

## 1. マーケティング・ゴールと設計思想

### 1.1 Core Value: 統合の価値

#### パラドックスの解決

```
従来の問題:
  多くのスキル = 「器用貧乏」「何でも屋」というネガティブな印象

解決策:
  足し算ではなく「掛け算」として提示
  Photo + Video + Code + Design = 4つの断片
  Photo × Video × Code × Design = 統合された唯一無二の価値
```

#### クライアントへの特異なメリット

| 価値カテゴリ | 従来のアプローチ | 千葉拓海のアプローチ | クライアントメリット |
|-------------|----------------|-------------------|-------------------|
| **コミュニケーション** | 写真家→デザイナー→開発者 (3回の翻訳) | 一人で完結 (ゼロ翻訳) | 意図のロスなし、時間短縮 |
| **一貫性** | 各専門家の「味」が混在 | 同一の美的感覚が貫通 | 強固なブランド体験 |
| **スピード** | 各専門家のスケジュール調整 | 撮影→コードまで直結 | 圧倒的なスピード |
| **効率性** | 人海戦術 | AIネイティブ開発 | コスト効率 + 市場投入スピード |

#### 言語化案

```
タグライン候補:

1. 「Visual × Technology × Sound」
   → 掛け算の視覚化、シンプル

2. 「One mind. Complete vision.」
   → 一人で完結する価値を英語で洗練

3. 「一人で完結。意図を形に。」
   → 日本語で直接的に価値を伝達

4. 「翻訳なしで、あなたのビジョンを形にする」
   → クライアント視点のベネフィット訴求
```

### 1.2 Target Psychology: ユーザージャーニー

#### Primary Target

```
美意識の高い経営者 / 決裁権者

属性:
- 年齢: 35-55歳
- 美意識: Apple, 無印良品, Braun の系譜に共感
- 価値観: 質 > 量、本質主義、長期的視点
- 課題: 「分かってくれる」クリエイターが見つからない
- 行動: 紹介ベースで動く、実績重視
```

#### 感情の変遷（5幕構造）

```
【第1幕: Intrigue】0-3秒
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
視覚体験: 漆黒の中の静謐な美しさ
内なる声: 「これは違う。普通じゃない」
感情状態: 知的好奇心の喚起
デザイン目標: Hero で一撃、情報過多を避ける

【第2幕: Recognition】3-15秒
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
視覚体験: ミニマリズム、無駄の排除
内なる声: 「この人は自分と同じ美意識を持っている」
感情状態: 同類認識、信頼の萌芽
デザイン目標: サイト自体が品質の証明

【第3幕: Discovery】15秒-2分
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
視覚体験: 多様な作品群の探索
内なる声: 「写真だけじゃない。動画も。Webも。全部ハイレベル」
感情状態: 驚き → 尊敬
デザイン目標: 作品の多様性を自然に提示

【第4幕: Realization】2-5分
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
認知内容: 効率性、一貫性、スピード、AIネイティブ
内なる声: 「一人でこれだけできるなら...」
感情状態: 合理的な魅力 → 取引欲求
デザイン目標: About/Services で価値を明確に

【第5幕: Action】Contact到達
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
内なる声: 「この人に相談してみよう」
感情状態: 確信 → 行動
デザイン目標: CTA障壁を最小化
```

#### ビジネスゴールへの接続

```
ユーザージャーニー          →  ビジネス成果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第1-2幕: 好奇心・同類認識   →  記憶に残る（後日の想起）
第3幕: 驚き・尊敬           →  「この人に頼みたい」の萌芽
第4幕: 価値理解             →  価格ではなく価値で判断される土台
第5幕: 行動                 →  質の高い相談が来る
                               ↓
                            【結果】良い案件 / 指名アサイン
```

### 1.3 CTA設計

#### 避けるべきアプローチ

- 「お問い合わせ」という汎用ボタン（差別化なし）
- 価格表の早期提示（価値理解前に価格判断される）
- サービスメニューの羅列（選択疲れ）
- 高圧的な「今すぐ」系CTA（経営者は急かされるのを嫌う）

#### 推奨アプローチ

```markdown
## CTA セクション構造

### Pre-CTA（文脈の構築）
「次のプロジェクトが見えてきた時に。
 あるいは、まだ漠然としたアイデアの段階でも。」

### CTA（行動の提案）
「対話を始める」
または
「30分の戦略セッションを予約」

### Post-CTA（不安の払拭）
「売り込みはしません。
 あなたのビジョンを聞かせてください。
 返信は48時間以内に。」
```

## 2. スキル・プレゼンテーション戦略

### 2.1 技術 → ビジネス価値への翻訳

| 技術的表現 | 非技術者向け翻訳 | ビジネスインパクト |
|-----------|-----------------|------------------|
| Next.js / React | 読み込みが速いサイト | 離脱率低下 → 売上向上 |
| TypeScript | バグの少ない安定システム | 信頼性 → 機会損失防止 |
| Tailwind CSS | 保守しやすい設計 | 長期的コスト削減 |
| Claude Code | AI活用の効率的開発 | 開発時間短縮 → コスト効率 |
| パフォーマンス最適化 | Google検索で上位表示 | 集客力向上 |
| アクセシビリティ | 誰もが使えるサイト | リーチ拡大 + 社会的責任 |

### 2.2 AIネイティブ開発スタイルの価値表現

#### 避けるべき表現

```
「AIを使って効率化しています」
→ 手抜き感、品質への不安を与える
```

#### 推奨する表現

```markdown
## AIネイティブ開発の価値

反復作業はAIに任せ、
創造的判断に集中する時間を最大化。

従来: 創造的作業 30% + 反復作業 70%
AIネイティブ: 創造的作業 70% + 反復作業 30%

人間の直感と、AIの実行速度。
両方を活かす開発スタイル。

結果: より良い判断 × より速い実行 = 品質とスピードの両立
```

### 2.3 エンジニアリング × クリエイティブの統合価値

```markdown
## デザインとコードを、同じ頭で考える

デザイナーが描いた夢を、
エンジニアが「技術的に無理」と否定する場面を見たことがあるだろう。

ここでは、その断絶は存在しない。

美しいものを美しいままコードに落とす。
「作りたいもの」と「作れるもの」の乖離がない。

結果：あなたが思い描いたものが、そのまま画面に現れる。
```

## 3. コピーライティング案

### 3.1 Hero セクション

```markdown
## Option A: 掛け算を可視化

Primary:   Visual × Technology × Sound
Secondary: 一人の視点で、すべてを形に。


## Option B: 完結性を強調

Primary:   One mind. Complete vision.
Secondary: 写真、映像、Web、体験設計。
           翻訳なしで、あなたの意図を形に。


## Option C: 本質主義

Primary:   ノイズを削ぎ落とし、本質だけを残す。
Secondary: フロントエンドエンジニア × デザイナー
           × フォトグラファー × ビデオグラファー


## Option D: 対話的

Primary:   あなたのビジョン、そのままに。
Secondary: 複数のスキルが一人の中で統合される時、
           翻訳ロスは消え、意図だけが残る。
```

### 3.2 About セクション

```markdown
一人で、完結する。

写真家として光を捉え、
映像作家として時間を編み、
エンジニアとして体験を構築する。

これらは別々のスキルではない。
一つの視点が、異なる媒体で表現されるだけだ。

複数の専門家を介する度に、意図は薄まる。
翻訳が重なる度に、本質からは遠ざかる。

あなたのビジョンを、
そのまま形にできる人間がここにいる。
```

### 3.3 Services セクション

```markdown
## Web Design & Development

デザインとコードを、同じ頭で考える。

デザイナーが描いた夢を、エンジニアが「技術的に無理」と
否定する場面を見たことがあるだろう。
ここでは、その断絶は存在しない。

美しいものを美しいままコードに落とす。
最新技術（Next.js, Tailwind）とAIネイティブな開発スタイルで、
スピードと品質を両立。


## Photography

撮る前に、使い方を知っている。

単なる写真撮影ではない。
Webのヒーロー画像として機能するか。
SNSでクロップした時にも成立するか。
印刷物で映えるか。

すべての出口を知っているから、
撮影現場での判断が変わる。


## Video Production

物語を、技術で支える。

撮影から編集、カラーグレーディングまで一貫。
映像の文法と、Webでの再生体験の両方を理解している。

結果：意図した感情が、意図した形で届く。
```

## 4. ブランドパーソナリティ

### 4.1 Brand as Person

```
もしこのブランドが人だったら:

- 寡黙だが、発言には重みがある
- 派手さはないが、存在感がある
- 聞く力があり、本質を見抜く
- 約束したことは必ず形にする
- トレンドに流されず、自分の軸がある
```

### 4.2 Voice Characteristics

| 特性 | 推奨 | 避ける |
|------|------|--------|
| **Confident** | 「〜します」 | 「〜できるかもしれません」 |
| **Concise** | 「一人で完結」 | 「一人ですべてを行うことが可能」 |
| **Direct** | 「翻訳ロスをなくす」 | 「コミュニケーションの齟齬を最小化」 |
| **Human** | 「あなたのビジョン」 | 「御社のご要望」 |
| **Specific** | 「10年来のクライアント」 | 「長年の実績」 |

## 5. 競合差別化

### 5.1 ポジショニングマップ

```
                    統合度
                      高
                       │
        ┌──────────────┼──────────────┐
        │              │    [千葉拓海] │
        │              │      ★       │
専門性  │──────────────┼──────────────│  汎用性
  深    │  [専門家]    │   [大手代理店]│   広
        │    ○        │      ○       │
        │              │              │
        └──────────────┼──────────────┘
                       │
                      低
                   (分断)

★ 千葉拓海の独自ポジション:
  - 専門家の深さ × 代理店の幅 × 個人の柔軟性
  - 「統合」と「専門性」の両立という稀有なポジション
```

### 5.2 Differentiation Statement

```markdown
## 千葉拓海 ポジショニング

For: 美意識が高く、質の高いクリエイティブを求める経営者

Who: 複数のベンダー調整に疲れ、一貫したブランド体験を求めている

千葉拓海 is: 統合クリエイティブ・パートナー

That: 写真・映像・Web・体験設計を一人の視点で完結させる

Unlike: 従来の「写真家」「デザイナー」「開発者」という分断されたサービス

Because: すべてのスキルをプロレベルで統合し、
         AIネイティブな開発スタイルで効率と品質を両立
```

## 6. 実装への指針

### 6.1 セクション別デザイン目標

| セクション | 感情目標 | 密度 | 滞在目安 |
|-----------|---------|------|---------|
| Hero | 好奇心、「違う」という直感 | 低 | 3-5秒 |
| Works | 驚き、尊敬 | 高 | 1-3分 |
| About | 信頼、共感 | 中 | 30秒 |
| Services | 具体的イメージ | 中 | 1分 |
| Contact | 確信、行動への準備 | 低 | 15秒 |

### 6.2 CTA配置

```
Primary CTA: Contact / 相談
  - 配置: Header（固定）+ Contact セクション
  - トーン: 低圧力、対話的
  - コピー: 「対話を始める」または「30分の戦略セッションを予約」

Secondary CTA: Works を見る
  - 配置: Hero 直下
  - 役割: 興味 → 探索への導線

Micro CTA: 各作品から Contact へ
  - 配置: 作品詳細ページ
  - トーン: 「この方向で相談したい時に」
```
