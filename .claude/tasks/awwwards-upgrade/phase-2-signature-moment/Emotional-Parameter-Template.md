# Emotional Parameter Design Template

**目的:** 各作品の感情を定義し、シェーダーパラメータに翻訳する
**使用:** Task 2.1 Enhanced 実装時
**所要時間:** 作品1つあたり 30-45分

---

## 📋 設計プロセス

### Step 1: 作品の理解（10分）

作品を深く理解する:

```markdown
## 作品: [タイトル]

### 作品の本質
- 何を作った？:
- 誰のため？:
- どんな課題を解決した？:

### 感情的なトーン
- この作品を一言で表すなら:
- 見た人にどう感じてほしいか:
- 作品の「温度」は？（冷たい/温かい/熱い）:

### 視覚的な印象
- 色の印象:
- 動きの印象（静的/動的）:
- 複雑さ（シンプル/複雑）:
```

---

### Step 2: 感情の言語化（5分）

3-5個のキーワードで感情を表現:

```
例1: 静謐なプロジェクト
→ 静けさ / 深み / 呼吸 / 余韻 / 洗練

例2: 革新的プロジェクト
→ 明快 / 構造 / 革新 / 前進 / 冷静

例3: 情熱的プロジェクト
→ 熱量 / 躍動 / 衝動 / 解放 / 炎

例4: 神秘的プロジェクト
→ 深淵 / 螺旋 / 複雑 / 瞑想 / 謎
```

**あなたの作品:**
```
→ _____ / _____ / _____ / _____ / _____
```

---

### Step 3: シェーダーパターン選択（5分）

キーワードから最も合うパターンを選択:

#### Pattern 0: Organic（有機的な流れ）

**適する感情:**
- 静けさ、流動、呼吸、自然、柔らかさ
- ゆっくり変化するもの
- 有機的なプロセス

**視覚:** 雲のような、水の流れのような動き

**選択基準:** 作品が「生きている」「呼吸している」感じなら Organic

---

#### Pattern 1: Geometric（幾何学的なセル）

**適する感情:**
- 構造、革新、明快、論理、効率
- システマティックなもの
- 技術的な精密さ

**視覚:** Voronoi セル、ハニカム構造

**選択基準:** 作品が「構築された」「設計された」感じなら Geometric

---

#### Pattern 2: Turbulent（炎のような乱流）

**適する感情:**
- 情熱、衝動、熱量、躍動、爆発
- エネルギッシュなもの
- 抑えきれない力

**視覚:** 炎、煙、乱流

**選択基準:** 作品に「熱」「動き」「解放」があるなら Turbulent

---

#### Pattern 3: Spiral（螺旋の渦）

**適する感情:**
- 深淵、神秘、複雑、瞑想、無限
- 内省的なもの
- 多層的な意味

**視覚:** 螺旋、渦、収束と拡散

**選択基準:** 作品が「深い」「何層もある」感じなら Spiral

---

**あなたの選択:**
```
Pattern: [ ] Organic  [ ] Geometric  [ ] Turbulent  [ ] Spiral

理由: _________________________________
```

### Step 4: パラメータ設定（15分）

#### 4.1 Octaves（複雑度）

**質問:** この作品の詳細レベルは？

```
3-4: シンプル、ミニマル、明快
    → 構造がはっきりしている作品
    → 一目で理解できるもの

5-6: 標準、バランス
    → ほとんどの作品に適用可能
    → 複雑すぎず、シンプルすぎず

7-8: 複雑、繊細、多層的
    → 見るほど発見がある作品
    → 何層も意味があるもの
```

**あなたの設定:**
```
octaves: [ 3 | 4 | 5 | 6 | 7 | 8 ]

理由: _________________________________
```

---

#### 4.2 Speed（動きの速度）

**質問:** この作品のリズムは？

```
0.1-0.2: 極めて遅い、瞑想的、静謐
         → 静かな作品
         → 時間をかけて鑑賞するもの

0.3-0.4: ゆっくり、落ち着いた
         → 穏やかな作品
         → リラックスした印象

0.5-0.6: 標準、適度な動き
         → バランスの取れた作品
         → ニュートラルな印象

0.7-0.8: 速い、動的、活発
         → エネルギッシュな作品
         → アクティブな印象

0.9-1.0: 極めて速い、激しい
         → 情熱的な作品
         → 衝動的な印象
```

**あなたの設定:**
```
speed: 0.___

理由: _________________________________
```

---

#### 4.3 Amplitude（振幅）

**質問:** 作品の存在感の強さは？

```
0.2-0.3: 控えめ、微か、繊細
         → 控えめな作品
         → 主張しすぎないもの

0.4-0.5: 適度、バランス
         → 標準的な作品
         → ニュートラルな存在感

0.6-0.7: 明確、強い、はっきり
         → 存在感のある作品
         → インパクトのあるもの

0.8: 極めて強い（使用注意）
     → 圧倒的な作品のみ
     → Pitch Black を損なう可能性
```

**あなたの設定:**
```
amplitude: 0.___

理由: _________________________________
```

---

#### 4.4 Temperature（温度）

**質問:** 作品の温度感は？

```
0.0-0.2: 極めて冷たい
         → 氷のような、機械的
         → Blue/Cyan 系の作品

0.3-0.4: 冷たい
         → クール、理性的
         → Cool Blue 系

0.5-0.6: 中性
         → 温度感がニュートラル
         → Purple/White 系

0.7-0.8: 温かい
         → 柔らかい、人間的
         → Amber/Orange 系

0.9-1.0: 熱い
         → 炎のような、情熱的
         → Red/Orange 系
```

**あなたの設定:**
```
temperature: 0.___

理由: _________________________________
```

#### 迷った時の判断基準

**"もし作品が人だったら？"**

```
静かに語りかける人 → Organic, low speed, low amplitude
論理的に説明する人 → Geometric, medium speed, medium amplitude
情熱的に訴える人 → Turbulent, high speed, high amplitude
深く考え込む人 → Spiral, low-medium speed, medium amplitude
```

## 📚 設計例（4作品）

### 例1: 静謐なポートフォリオサイト

```ts
{
  emotion: {
    colorHex: "#ffbf49",        // Amber - 温かみ
    octaves: 6,                 // 繊細な詳細
    speed: 0.1,                 // ゆっくり
    amplitude: 0.3,             // 控えめ
    pattern: "organic",         // 有機的な流れ
    temperature: 0.7,           // やや温かい
  }
}

// 理由:
// - 静謐さを表現するため、速度を最小限に
// - 細かい詳細で深みを出す（octaves: 6）
// - 有機的なパターンで「呼吸」を感じさせる
```

---

### 例2: 革新的なSaaSプロダクト

```ts
{
  emotion: {
    colorHex: "#4a9eff",        // Cool Blue - 革新
    octaves: 3,                 // シンプルで明快
    speed: 0.5,                 // 適度に動的
    amplitude: 0.6,             // 存在感あり
    pattern: "geometric",       // 構造的
    temperature: 0.3,           // 冷静
  }
}

// 理由:
// - 技術的な革新を幾何学模様で表現
// - シンプルさを重視（octaves: 3）
// - 動きで「前進感」を出す（speed: 0.5）
```

---

### 例3: 情熱的なブランドキャンペーン

```ts
{
  emotion: {
    colorHex: "#e74c3c",        // Red - 情熱
    octaves: 4,                 // 適度な複雑さ
    speed: 0.8,                 // 激しい
    amplitude: 0.7,             // 強い
    pattern: "turbulent",       // 乱流
    temperature: 0.9,           // 熱い
  }
}

// 理由:
// - 情熱を炎のような乱流で表現
// - 高速な動きで「躍動感」
// - 強い振幅で「熱量」を伝える
```

---

### 例4: 神秘的なアートプロジェクト

```ts
{
  emotion: {
    colorHex: "#9b59b6",        // Purple - 神秘
    octaves: 8,                 // 極めて複雑
    speed: 0.2,                 // 瞑想的
    amplitude: 0.5,             // 中程度
    pattern: "spiral",          // 螺旋
    temperature: 0.5,           // 中性
  }
}

// 理由:
// - 多層的な意味を複雑なパターンで表現
// - 螺旋で「深淵」「無限」を示唆
// - ゆっくりした動きで「内省」を促す
```

## ⚠️ よくある間違い

### 間違い 1: すべて同じパターン

```
❌ 全作品を Organic にする
→ 単調、差がない

✅ 作品ごとに異なるパターンを選ぶ
→ 多様性、発見
```

### 間違い 2: 極端な値

```
❌ speed: 1.0, amplitude: 0.8
→ 動きすぎて Pitch Black を損なう

✅ 控えめから始めて、必要なら強化
```

### 間違い 3: 理由なき選択

```
❌ "なんとなく Purple"
→ 感情が伝わらない

✅ "神秘的な内容だから Purple"
→ 意図が明確
```
