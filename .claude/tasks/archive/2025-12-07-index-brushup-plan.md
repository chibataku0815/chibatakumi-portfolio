## 現状分析

### 構成
```
page.tsx
├── Hero Section
│   ├── HeroShaderBackground (layout.tsx で配置)
│   └── HeroText (タイトル + タグライン + スクロールインジケーター)
│
└── Works Section
    ├── FluidGradientBackground (sticky)
    └── HorizontalWorks (4パネル水平スクロール)
```

### 問題点（各スキル観点）

#### Art Direction 観点
| 問題 | 詳細 |
|------|------|
| ビジュアルナラティブの欠如 | Hero → Works の流れが「次のセクション」程度で物語性がない |
| インパクトポイントの未設計 | Entry Impact はあるが Discovery Moments が弱い |
| マルチクリエイター表現の欠如 | 「コードを書く。撮る。編む。」の多面性がビジュアルで表現されていない |
| ムードの断絶 | 背景シェーダーは良いが前景コンテンツが世界観を表現していない |

#### Visual Composition 観点
| 問題 | 詳細 |
|------|------|
| 中央配置の多用 | Hero、Works パネルともに中央配置で構図に動きがない |
| グリッドシステムの欠如 | 体系的なグリッドなしの配置 |
| 視線誘導の弱さ | 視線の流れが設計されていない |
| テンションの欠如 | すべてが安全な配置で視覚的緊張感がない |
| ネガティブスペースの未活用 | 余白が意図的でなく「たまたまある」だけ |

#### Motion Design 観点
| 問題 | 詳細 |
|------|------|
| リズムの欠如 | 全体を通じたリズム設計がない |
| トランジションの平凡さ | Hero → Works の遷移が単なる移動 |
| 間の不足 | 動きが連続して呼吸がない |
| 感情的ペーシングの欠如 | 緊張と解放の波がない |

#### Typography 観点
| 問題 | 詳細 |
|------|------|
| 階層の弱さ | タイトルとタグラインのコントラスト不足 |
| 表現としての文字 | 文字が「読むもの」のみで「見るもの」になっていない |

## ブラッシュアップ方針

### ビジュアルコンセプト強化

**Core Identity の再定義:**
```
「漆黒の中に棲む熱を持った知性」
→ 静かだが触れると熱い
→ 表面は抑制、内側に強度
```

**Visual Metaphor:**
```
溶岩流の表面
- 黒く冷えた外見
- 触れれば火傷するような熱が潜む
- 時折、割れ目から光が漏れる
```

### ナラティブアーク設計

```
Hero (Exposition)
  │ 「静かな出会い」
  │ 名前とアイデンティティの提示
  │ 漆黒の中に浮かぶ存在
  │
  ▼ [Transition: 沈降する感覚]
  │
Works (Rising Action)
  │ 「能力の開示」
  │ 4つの領域を横断
  │ 各領域で異なる「熱」を感じさせる
  │
  ▼ [To be continued...]
```

## 実装計画

### Phase 1: Hero Section リデザイン

#### 1.1 構図の改善 (visual-composition)

**Before:**
```
┌─────────────────────────────────────┐
│                                     │
│          Takumi Chiba               │
│     コードを書く。撮る。編む。         │
│                                     │
│            [scroll]                 │
└─────────────────────────────────────┘
```

**After (案A: 非対称配置):**
```
┌─────────────────────────────────────┐
│                                     │
│                    Takumi           │
│                    Chiba            │
│                                     │
│  コードを書く。                       │
│  撮る。                             │
│  編む。                             │
│                           [scroll]  │
└─────────────────────────────────────┘
```

**After (案B: 縦分割):**
```
┌─────────────────────────────────────┐
│         │                           │
│    T    │                           │
│    a    │   コードを書く。            │
│    k    │   撮る。                   │
│    u    │   編む。                   │
│    m    │                           │
│    i    │                  [scroll] │
│         │                           │
└─────────────────────────────────────┘
```

**決定ポイント:** どちらの構図を採用するか

#### 1.2 タイポグラフィ強化 (typography)

- **タイトル**: より大きく、より存在感を
  - 現在: `clamp(2.75rem, 10vw, 7rem)`
  - 提案: `clamp(4rem, 15vw, 12rem)` + 文字間調整

- **タグライン**: 3行分離で階層を作る
  - 「コードを書く。」「撮る。」「編む。」を個別に
  - 各行にホバーで反応を

- **書体検討**:
  - 現在: Geist Sans
  - 検討: Display用に別書体を追加？ または Geist を極端なサイズで使い倒す

#### 1.3 エントリーアニメーション (motion-design)

**現在のシーケンス:**
```
T+0.0s: Title chars reveal (blur→sharp, stagger 35ms)
T+0.7s: Tagline fade-in
T+1.0s: Scroll indicator
```

**提案シーケンス:**
```
T+0.0s: 画面全体が一瞬「呼吸」（背景の微細な動き）
T+0.3s: タイトル1文字目が現れる（大きく、遅く）
T+0.6s: 残りの文字が追従（加速しながら）
T+1.2s: タグライン1行目「コードを書く。」
T+1.5s: タグライン2行目「撮る。」
T+1.8s: タグライン3行目「編む。」
T+2.2s: 静寂の「間」（0.5秒）
T+2.7s: スクロールインジケーター（控えめに）
```

**ポイント:**
- 最初の1文字に重みを
- タグラインは「打ち込む」ようなリズム
- 全体完了後に「沈黙」を入れる

#### 1.4 インタラクション追加

- **マウス追従**: タイトル文字がカーソルに微細に反応
- **スクロールヒント**: スクロール前の「予感」演出
- **ホバー on タグライン**: 各行にホバーで微細なアンバーglow

### Phase 2: Hero → Works トランジション

#### 2.1 現状の問題

```
現在:
Hero section が画面外に出る
↓
Works section が現れる
↓
背景が FluidGradient に切り替わる

→ 単なる「セクション移動」で、物語的繋がりがない
```

#### 2.2 提案: 「沈降」トランジション

**コンセプト:**
```
Hero の世界から「深く沈む」ように Works の世界へ
- 表面（Hero）から深海（Works）へ
- 光が減り、流体の世界へ
```

**実装案:**
```
1. Hero コンテンツが上へ消えていく（parallax）
2. 背景シェーダーが徐々に暗く、流体的に変化
3. HeroShader → FluidGradient のクロスフェード
4. Works の最初の文字が「浮き上がる」ように現れる
```

**技術的検討:**
- 2つのシェーダー背景のブレンド
- または、HeroShader 自体に流体的な変化を追加
- ScrollTrigger で制御

### Phase 3: Works Section リデザイン

#### 3.1 構図の改善

**現在:**
```
┌─────────────────────────────────────┐
│  01                                 │
│                                     │
│       Web Development               │
│                                     │
│    Digital Experiences              │
│                                     │
│    [description text...]            │
│                                     │
│         ━━━━━ 45%                   │
└─────────────────────────────────────┘
```

**提案 (案A: 非対称レイアウト):**
```
┌─────────────────────────────────────┐
│                                     │
│  01                                 │
│  Web Development                    │
│                                     │
│              Digital                │
│              Experiences            │
│                                     │
│                                     │
│  [description                       │
│   aligned left...]     ━━━━━ 45%   │
└─────────────────────────────────────┘
```

**提案 (案B: 大きな数字):**
```
┌─────────────────────────────────────┐
│                                     │
│     0 1                             │
│                                     │
│         Digital                     │
│         Experiences                 │
│                                     │
│     Web Development                 │
│                                     │
│     [desc...]          ━━━━━ 45%   │
└─────────────────────────────────────┘
```

#### 3.2 各パネルの差別化

**現在:** 全パネルが同じレイアウト

**提案:** 各パネルに微細なレイアウト変化
- Panel 1: 右寄せ
- Panel 2: 左寄せ
- Panel 3: 下寄せ
- Panel 4: 中央（終点として）

→ 移動するたびに視覚的新鮮さ

#### 3.3 パネル間トランジション (motion-design)

**現在:**
```
コンテンツ fade out → 横移動 → コンテンツ fade in
```

**提案:**
```
1. 現パネルのテキストが「散る」（文字が dissolve）
2. トランジションライン（維持、より強調）
3. 次パネルへの横移動
4. 新しい構図で文字が「集まる」
```

#### 3.4 プログレス表現の強化

**現在:** 下部のプログレスバー

**追加案:**
- パネル番号（01, 02, 03, 04）を大きく表示
- 番号自体がプログレスを表現（塗りつぶしアニメーション）
- 右側ドットナビゲーションをより洗練

---

### Phase 4: 視覚言語の統一

#### 4.1 グラフィック要素の追加

**導入する要素:**
```
1. アクセントライン
   - 水平線: セクション区切り
   - 斜め線: 動きの示唆
   - 太さ: 1-2px（繊細）

2. マイクロパターン
   - ドット: 進行状況
   - グリッド: 背景テクスチャ（控えめ）

3. アンバーアクセント
   - 現在: ほぼ未使用
   - 提案: インタラクション時の「熱」として
```

#### 4.2 カラー活用の強化

**現在の使用:**
- 背景: 漆黒 (slate-1, slate-2)
- テキスト: オフホワイト (slate-12)
- アクセント: ほぼなし

**提案:**
```
通常状態: 漆黒 + オフホワイト（現状維持）
ホバー/アクティブ: アンバーが「にじむ」
重要ポイント: アンバーの光漏れ
```
