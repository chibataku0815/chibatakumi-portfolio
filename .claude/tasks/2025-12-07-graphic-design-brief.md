```
「漆黒の中に棲む熱を持った知性」

```
溶岩流の表面

## 1. ロゴ/シンボルマーク

### 1.1 メインロゴ（シンボル）

**用途:**
- ページトランジション時の中央表示
- ファビコン
- OGP画像

**要件:**
```
サイズ: 80×80px 基準（SVGでスケーラブル）
スタイル:
  - モノライン（単線）推奨
  - ストロークアニメーション対応（path形式）
  - 複雑すぎない（3-5秒で描画完了する程度）

表現の方向性:
  - 「TC」のモノグラム
  - または抽象的なシンボル
  - 「コード/撮影/編集」を暗示する要素があれば尚良い
```

**避けるべきもの:**
- 過度に装飾的なもの
- 細かすぎるディテール
- 閉じた塗りつぶし領域が多いもの（アニメーション困難）

**納品形式:**
```
- logo-symbol.svg（パス結合版、ストロークアニメーション用）
- logo-symbol-fill.svg（塗りつぶし版、ファビコン用）
- サイズバリエーション: 16px, 32px, 80px, 120px
```

### 1.2 ワードマーク（オプション）

**用途:**
- Nav左上
- フッター

**要件:**
```
「Takumi Chiba」または「TC」のタイポグラフィ加工
- Geist Sans ベース or カスタム
- 微細なカスタマイズ（文字間、ウェイト調整）
```

## 2. 装飾SVG要素

### 2.1 アクセントライン

**用途:**
- セクション区切り
- テキストの強調下線
- トランジション時の視覚要素

**要件:**
```
バリエーション:
  a) 水平線（実線、破線、グラデーション）
  b) 斜め線（動きの示唆）
  c) 角括弧的な装飾 [ ] や < >

スタイル:
  - 太さ: 1-2px
  - 色: オフホワイト（--text-base）
  - 長さ: 可変（100%, 50%, 固定幅）

ファイル名例:
  - line-horizontal.svg
  - line-diagonal.svg
  - bracket-left.svg
  - bracket-right.svg
```

### 2.2 装飾パターン

**用途:**
- 背景テクスチャ（控えめ）
- セクション背景のアクセント

**要件:**
```
バリエーション:
  a) ドットグリッド（微細、opacity 5-10%）
  b) 斜線パターン
  c) 抽象的なノイズ/グレイン（SVGフィルター）

注意:
  - 過度に目立たない
  - パフォーマンス考慮（単純な形状）
```

### 2.3 セクション番号装飾

**用途:**
- Works セクションの「01」「02」などの表示

**要件:**
```
現状: 小さなテキスト
提案: 大きな装飾的数字

スタイル案:
  a) アウトライン数字（塗りなし、線のみ）
  b) 半透明の大きな数字
  c) ステンシル風（一部欠けている）

サイズ: 画面の 30-50% 程度の高さ
```

## 3. タイポグラフィ加工

### 3.1 Hero タイトル「Takumi Chiba」

**現状:** Geist Sans そのまま

**加工案:**
```
a) カスタムレタリング
   - 名前全体をオリジナルデザイン
   - SVGとして書き出し

b) 部分加工
   - 特定の文字のみカスタマイズ
   - 例: 「T」「C」のイニシャルを特別に

c) タイポグラフィミックス
   - 一部をセリフ体、一部をサンセリフ
   - 「Takumi」と「Chiba」で異なるスタイル
```

**推奨:** まずは既存フォントで実装し、後からカスタムSVGに差し替え可能な設計にする

### 3.2 タグライン加工

**現状:** 「コードを書く。撮る。編む。」

**加工案:**
```
各行を個別のSVGテキストとして書き出し:
  - コードを書く。
  - 撮る。
  - 編む。

スタイル:
  - 日本語フォント: 游ゴシック / Noto Sans JP / 筑紫ゴシック
  - 少し細め（Light〜Regular）
  - 文字間調整済み
```

## 4. アイコンセット（オプション）

### 4.1 ナビゲーションアイコン

**用途:**
- モバイルメニュー
- 各セクションの識別子

**要件:**
```
サイズ: 24×24px 基準
スタイル: モノライン、1.5-2px ストローク
色: currentColor（CSS制御可能）

必要なアイコン:
  - メニュー（ハンバーガー）
  - 閉じる（×）
  - 矢印（上下左右）
  - 外部リンク
```

### 4.2 カテゴリアイコン

**用途:**
- Motion / Interactive / Installation / Archive / Contact の識別

**要件:**
```
各カテゴリを象徴する抽象的なシンボル:
  - Motion: 動きを表す形状
  - Interactive: インタラクションを表す形状
  - Installation: 空間を表す形状
  - Archive: アーカイブを表す形状
  - Contact: コンタクトを表す形状
```

## SVG 最適化ガイドライン

### Illustrator 書き出し設定

```
1. ファイル > 書き出し > スクリーン用に書き出し
2. 形式: SVG
3. スタイル: インラインスタイル
4. フォント: アウトライン化（SVGフォントは使わない）
5. 小数点以下: 1桁
6. 圧縮: なし（後で最適化）
```

### 最適化チェックリスト

- [ ] 不要なグループ削除
- [ ] 不要なメタデータ削除
- [ ] パスの単純化
- [ ] viewBox の設定確認
- [ ] currentColor の使用（色を CSS で制御する場合）

## 進め方

### 推奨フロー

```
1. ロゴ/シンボルのラフスケッチ（複数案）
2. 方向性の確認・選定
3. ベクター化・詳細デザイン
4. SVG書き出し・最適化
5. コード統合（Claude Code）
```
