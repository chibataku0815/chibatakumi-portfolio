# Excellence Framework

**すべてのスキルに共通する卓越性の評価基準**

このフレームワークは「作品賞を受賞するレベル」の成果物を生み出すための評価軸を定義する。

---

## The Five Levels of Excellence

```
Level 5: Award-Worthy（受賞レベル）
         ↑ 新しい基準を作る、業界に影響を与える
Level 4: Distinctive（差別化）
         ↑ 他にない個性、感情的インパクト
Level 3: Refined（洗練）
         ↑ 細部まで磨かれている、意図が明確
Level 2: Professional（プロフェッショナル）
         ↑ 業界標準を満たす、一貫性がある
Level 1: Functional（機能的）
         ↑ 要件を満たす、エラーがない
```

---

## Level Definitions

### Level 1: Functional（機能的）
**基準**: 要件を満たし、動作する

```
□ 技術的に正常動作
□ 基本的なUX要件を満たす
□ エラー・バグがない
□ アクセシビリティの最低基準
```

**典型例**: 一般的なコーポレートサイト、テンプレートベースの実装

---

### Level 2: Professional（プロフェッショナル）
**基準**: 業界標準を満たし、プロの仕事として恥ずかしくない

```
□ 視覚的に一貫性がある
□ パフォーマンス基準を満たす（LCP < 2.5s）
□ レスポンシブ対応が適切
□ コードが整理されている
□ ユーザーが迷わない導線
```

**典型例**: 中堅デザインエージェンシーの制作物

---

### Level 3: Refined（洗練された）
**基準**: 細部まで磨かれ、意図が明確

```
□ 微細なアニメーションが心地よい
□ タイポグラフィに意図がある
□ 余白が戦略的に設計されている
□ 色彩に統一された意図がある
□ インタラクションにフィードバックがある
□ 「この選択の理由」を説明できる
```

**典型例**: 優良デザインエージェンシーの制作物、Dribbble人気作品

---

### Level 4: Distinctive（差別化された）
**基準**: 他にない個性を持ち、感情的インパクトを与える

```
□ 見た瞬間に記憶に残る
□ 「これは何か違う」と感じさせる
□ 技術と美学が融合している
□ 独自の世界観が確立している
□ 業界関係者から注目される
□ 模倣したくなる要素がある
□ スクリーンショットを撮りたくなる
```

**典型例**: Awwwards Honorable Mention、FWA ノミネート

---

### Level 5: Award-Worthy（受賞レベル）
**基準**: 新しい基準を作り、業界の進化に貢献する

```
□ 見たことのない表現がある
□ 技術的革新がある
□ 感情を強く揺さぶる
□ 他のクリエイターに影響を与える
□ 何度でも訪問したくなる
□ 数年後も参照される
□ カテゴリを再定義する可能性
```

**典型例**: Awwwards Site of the Day/Year、FWA受賞、CSS Design Awards

---

## Quality Dimensions

各レベルは以下の5つの次元で評価される:

### 1. Visual Impact（視覚的インパクト）

| Level | 基準 |
|-------|------|
| L1 | 見える、読める |
| L2 | 整っている、統一感がある |
| L3 | 美しい、細部まで磨かれている |
| L4 | 印象的、記憶に残る |
| L5 | 衝撃的、新しい美を提示 |

### 2. Motion & Interaction（動きとインタラクション）

| Level | 基準 |
|-------|------|
| L1 | 状態が変わることがわかる |
| L2 | スムーズに遷移する |
| L3 | 心地よいタイミングとイージング |
| L4 | 動きに意味と感情がある |
| L5 | 動きが物語を紡ぐ、新しいパターン |

### 3. Technical Craft（技術的工芸）

| Level | 基準 |
|-------|------|
| L1 | 動く |
| L2 | 効率的に動く |
| L3 | 最適化されている |
| L4 | 技術が表現を可能にしている |
| L5 | 技術的革新がある |

### 4. Emotional Resonance（感情的共鳴）

| Level | 基準 |
|-------|------|
| L1 | 邪魔しない |
| L2 | 快適 |
| L3 | 心地よい |
| L4 | 感情を動かす |
| L5 | 忘れられない体験 |

### 5. Conceptual Clarity（コンセプトの明確さ）

| Level | 基準 |
|-------|------|
| L1 | 何かはわかる |
| L2 | 意図がわかる |
| L3 | 意図が一貫している |
| L4 | 独自の世界観がある |
| L5 | 新しい視点を提示している |

## Award-Worthy Checklist

**受賞レベルに到達するための最終チェックリスト**

### The "Wow" Test
```
□ 初見で「これは違う」と感じるか？
□ スクロールを続けたくなるか？
□ 誰かに見せたくなるか？
□ スクリーンショットを撮りたくなるか？
□ 何度も訪問したくなるか？
```

### The "Why" Test
```
□ すべての要素に「なぜ」の答えがあるか？
□ その「なぜ」は表層的でなく本質的か？
□ 削除できる要素はないか？
□ 追加すべき要素はないか？
```

### The "Details" Test
```
□ 404ページまで設計されているか？
□ ローディング状態は美しいか？
□ エラー状態は適切か？
□ スクロールの終端まで配慮されているか？
□ カーソル変化に意図があるか？
```

### The "Performance" Test
```
□ LCP < 2.5s か？
□ CLS < 0.1 か？
□ 60fps を維持しているか？
□ 低スペック端末でも体験が成り立つか？
```

### The "Longevity" Test
```
□ 1年後も古く見えないか？
□ トレンドに依存しすぎていないか？
□ 本質的な価値があるか？
```

## Reference Standards

### Awwwards 評価基準（参考）

| 基準 | 配点 | Level 5 に必要なスコア |
|------|------|----------------------|
| Design | 40% | 9.0+ |
| Creativity | 25% | 9.0+ |
| Content | 20% | 8.5+ |
| UX | 15% | 8.5+ |

### Site of the Day 共通特性

```
1. 第一印象の強さ
   - Hero で世界観を確立
   - 3秒以内に「何か違う」を伝える

2. 技術と美学の融合
   - WebGL/Canvas の創造的使用
   - パフォーマンスを犠牲にしない表現

3. 一貫した世界観
   - すべての要素が同じ言語を話す
   - 細部まで設計意図がある

4. 予想を裏切る瞬間
   - 「こう来るか」という驚き
   - しかし文脈に沿った驚き

5. 記憶に残る終わり方
   - フッター/最後のインタラクションの重要性
   - 余韻を残す
```

## Usage

### スキル呼び出し時
```
すべてのクリエイティブ/実装作業の前に:
1. 現状レベルを評価
2. 目標レベルを設定（通常 L4-5）
3. ギャップを特定
4. 作業完了後に再評価
```

### 品質レビュー時
```
成果物の最終確認:
1. Award-Worthy Checklist を実行
2. 各次元のレベルを評価
3. Level 5 に満たない次元を特定
4. 改善策を実施
```

---

## Philosophy

> **「良い」は敵。「素晴らしい」を目指す。**
>
> Level 3（洗練された）で満足しない。
> Level 4（差別化された）で妥協しない。
> Level 5（受賞レベル）を当然の目標とする。
>
> これは傲慢ではなく、基準の設定。
> 到達できなくても、目指すことで Level 4 に到達する。
> Level 3 を目指すと Level 2 になる。
