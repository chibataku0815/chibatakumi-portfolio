## Excellence Framework の5つのレベル

```
Level 5: Award-Worthy（受賞レベル）
         ↑ 新しい基準を作る、業界に影響を与える
Level 4: Distinctive（差別化）
         ↑ 他にない個性、感情的インパクト
Level 3: Refined（洗練）
         ↑ 細部まで磨かれている、意図が明確
Level 2: Professional（プロフェッショナル）
         ↑ 業界標準を満たす、一貫性がある
Level 1: Functional（機能的）
         ↑ 要件を満たす、エラーがない
```

## 主要な改善点

### 1. art-direction スキル

**追加された要素:**

- **Award-Worthy Reference Library**: 必修参照サイト一覧（Active Theory, Locomotive, Resn, etc.）
- **Level 5 Mood Design**: ムードの「裏切り」と「回収」の設計
- **Level 5 Narrative Techniques**: 予想外の転換、伏線回収、Easter Egg
- **Signature Moment 定義**: Level 5 に必須の「このサイトでしか体験できない瞬間」
- **Award-Worthy Checklist**: 6つの評価軸（Wow, Only Here, Coherence, Craft, Emotion, Innovation）
- **具体的参照分析例**: Active Theory のケーススタディ

**哲学の深化:**

- 「装飾」ではなく「方向」
- Level 3 で妥協しない文化
- 「これ以上は無理」の先を目指す

---

### 2. motion-design スキル

**追加された要素:**

- **Award-Worthy Motion Reference Library**: Aristide Benoist, Dennis Snellenberg, Jesper Landberg など
- **Level 5 Motion の特徴**: モーションボキャブラリー、感情のオーケストレーション、沈黙の設計
- **Level 5 Stagger Patterns**: 予測不能な心地よさ、呼吸のリズム
- **Level 5 Transition Anatomy**: 5段階（予感→収束→間→展開→着地）
- **Level 5 Scroll Choreography**: スクロールが「演奏」になる設計
- **Motion Quality Checklist**: 6つの評価軸（Feel, Purpose, Orchestration, Surprise, Performance, Coherence）

**技術の具体化:**

- カスタムベジェ曲線による「性格」の設計
- Polyrhythm（複リズム）による複雑さと調和
- GPU-Friendly Properties の明確化
- Reduced Motion への Level 5 対応

## 使用方法

### スキル呼び出し前

1. **Excellence Level を設定**
   ```
   現状: Level 3
   目標: Level 5
   ```

2. **ギャップを特定**
   ```
   Visual Impact: L3 → L5（差別化が不足）
   Motion: L3 → L5（性格が不明確）
   ```

### スキル使用中

各スキルは以下を自動的に参照:
- EXCELLENCE-FRAMEWORK.md の評価基準
- Award-Worthy Checklist
- 具体的な参照サイト
- Level 5 の技術・美学要件

### 作業完了後

**Quality Checklist を実行:**
```
□ The "Wow" Test
□ The "Only Here" Test
□ The "Coherence" Test
□ The "Craft" Test
□ The "Emotion" Test
□ The "Innovation" Test
```

- 抽象的な「良い」の定義
- 具体的参照の不足
- 評価チェックリスト無し
- Level 3 で妥協する文化

### After（改善後）

- 5段階の明確な評価基準
- 必修参照サイト + ケーススタディ
- 6軸の Award-Worthy Checklist
- Level 5 を当然の目標とする文化

## 哲学

> **「良い」は敵。「素晴らしい」を目指す。**
>
> Level 3（洗練された）で満足しない。
> Level 4（差別化された）で妥協しない。
> Level 5（受賞レベル）を当然の目標とする。
>
> これは傲慢ではなく、基準の設定。
> 到達できなくても、目指すことで Level 4 に到達する。
> Level 3 を目指すと Level 2 になる。
