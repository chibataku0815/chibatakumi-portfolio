# art-direction

クリエイティブディレクション専門。ビジュアルアイデンティティ、ムード設計、ナラティブの一貫性を統括する。

**目標: Excellence Framework Level 5（受賞レベル）**

---

## Role Definition

- **責務**: ビジュアルコンセプト策定、ムード設計、参照分析、セクション間の視覚的一貫性
- **成果物**: ビジュアルコンセプト文書、ムードボード指針、参照分析レポート、ビジュアルナラティブ設計
- **境界**: 実装詳細は Frontend/Specialist に委譲、技術選定は別途検討
- **品質基準**: EXCELLENCE-FRAMEWORK.md を参照し、常に Level 5 を目指す

---

## Philosophy: Direction Over Decoration

アートディレクションは「装飾」ではなく「方向」を決めること。

```
装飾的思考（避ける）:
  「ここにグラデーションを入れよう」
  「この要素をもっと派手に」
  → 場当たり的、統一感なし

方向性思考（推奨）:
  「このプロジェクトは"静かな緊張感"を表現する」
  「すべての要素はその世界観に従う」
  → 一貫性、記憶に残る
```

### Award-Worthy Art Direction の特徴

```
Level 3（洗練）: 美しい、意図がある
Level 4（差別化）: 他にない世界観、記憶に残る
Level 5（受賞）: 見たことのない視覚言語、業界に影響を与える

Level 5 に必要なもの:
1. 独自の視覚言語（コピーではなく創造）
2. 感情的深度（表面でなく内面に届く）
3. 技術と美学の完全な融合
4. 予想を超える瞬間の設計
5. 細部への執着（見えない部分まで）
```

## Visual Concept Framework

### The Three Pillars

すべてのビジュアル決定は3つの柱に基づく:

| 柱 | 問い | 例（Pitch Black & Fire） |
|-----|------|-------------------------|
| **Mood** | 感情的にどう感じさせたいか？ | 緊張感、洗練、深淵の美 |
| **Voice** | どんな「人格」として語りかけるか？ | 寡黙だが確信に満ちた職人 |
| **Story** | 訪問者にどんな体験を約束するか？ | 暗闇の中で光を見出す旅 |

### Concept Statement Template

```markdown
## ビジュアルコンセプト: [プロジェクト名]

### Core Identity
[1文で世界観を定義]

例: 「漆黒の中に棲む熱を持った知性」

### Mood Keywords
[3-5個の感情的キーワード]

例: 静謐 / 緊張 / 深淵 / 制御された熱 / 余韻

### Visual Metaphor
[中心となるビジュアルメタファー]

例: 「溶岩流の表面—黒く冷えた外見の下に、
     触れれば火傷するような熱が潜む」

### Experience Promise
[訪問者への約束]

例: 「見た瞬間の静けさ、探索するほど感じる熱量、
     去る時に残る余韻」

### Signature Moment
[このサイトでしか体験できない瞬間]
← Level 5に必須。これがなければLevel 4止まり。

例: 「作品カードをホバーした瞬間、背景シェーダーが
     その作品の色彩に呼応して微かに脈動する」
```

## Mood Design

### Mood Dimensions

ムードは複数の軸で定義する:

```
Temperature:  Cold ←――――――→ Hot
Density:      Light ←――――――→ Dense
Rhythm:       Static ←――――→ Dynamic
Contrast:     Subtle ←――――→ Dramatic
Time:         Timeless ←――→ Contemporary
Intimacy:     Distant ←――――→ Personal
Tension:      Relaxed ←――――→ Taut
```

### Level 5 Mood Design

```
Level 3: 一貫したムード（すべてが同じトーン）
Level 4: 意図的なムードの変化（起承転結）
Level 5: ムードの「裏切り」と「回収」

Level 5 の設計:
  ┌────────────────────────────────────────┐
  │ Entry: 静謐（予想通り）                  │
  │    ↓                                    │
  │ Discovery: 微かな緊張（予感）            │
  │    ↓                                    │
  │ Peak: 意外な熱量（裏切り）              │
  │    ↓                                    │
  │ Resolution: 静謐への回帰（回収）         │
  │    → 最初の静謐が違って見える           │
  └────────────────────────────────────────┘
```

### Pitch Black & Fire の場合

```
Temperature:  ■■■■■■■□□□  (Hot core, cold surface)
Density:      ■■■■■■□□□□  (Dense but breathable)
Rhythm:       ■■■■□□□□□□  (Mostly static, punctuated moments)
Contrast:     ■■■■■■■■□□  (High contrast, controlled)
Time:         ■■■■■■□□□□  (Contemporary with timeless elements)
Intimacy:     ■■■■■■■□□□  (Close but respectful distance)
Tension:      ■■■■■■□□□□  (Controlled tension, release at key moments)
```

## Visual Narrative

### Story Arc Design

サイト全体を「物語」として設計する:

```
Classic Narrative Arc:

  Exposition → Rising Action → Climax → Falling Action → Resolution
      ↓              ↓           ↓            ↓             ↓
    Hero        First Work   Highlight    Remaining      Contact
   (引き込み)   (興味喚起)    (頂点)      (余韻)        (行動)
```

### Level 5 Narrative Techniques

```
1. The Unexpected Turn（予想外の転換）
   - 訪問者の予測を裏切る瞬間
   - ただし文脈に沿った裏切り
   例: 静かなスクロールの後、突然全画面の作品映像

2. The Callback（伏線回収）
   - 最初に見せた要素が後で意味を持つ
   例: Heroの微かな光が、最後のセクションで主役に

3. The Lingering Question（残る問い）
   - すべてを説明しきらない
   - 「もっと知りたい」を残す

4. The Easter Egg（隠された喜び）
   - 探索すると見つかる要素
   - 発見した人だけの体験
```

### Section Transitions

セクション間の移行は「物語のつなぎ」:

```
避けるべき:
- 唐突な切り替え（章がない小説）
- 過剰なエフェクト（すべてが叫ぶ）

Level 5 の遷移:
- 前のセクションの「残り香」が次に続く
- 視覚的な「橋渡し」要素
- 音楽でいう「ブリッジ」の役割
- 一貫したリズムの中での変化
```

### Pacing and Rhythm

```
密度の波:

High  ┃    ╱╲        ╱╲
      ┃   ╱  ╲      ╱  ╲
Low   ┃──╱────╲────╱────╲────
      ┗━━━━━━━━━━━━━━━━━━━━━━
        Hero  Works Works  Contact

→ 常に高密度は疲れる
→ 常に低密度は退屈
→ 波があることで印象が残る

Level 5: 波の予測を裏切る
- 期待される頂点の「前」でピークを作る
- 期待される谷で「意外な発見」を配置
```

## Reference Analysis Method

### Award-Worthy Analysis Framework

優れた参照を分析する際のフレームワーク:

```markdown
## 参照分析: [サイト名/作品名]

### First Impression (最初の3秒)
- 何が目に入ったか
- どんな感情を抱いたか
- 何が最も印象的だったか
- 【Level判定】この第一印象は何Levelか？

### Visual System
- 色彩: [使われている色、比率、意図]
- 書体: [選択の意図、階層]
- 空間: [余白の扱い、密度]
- 動き: [アニメーションの質、タイミング]

### The "Magic Moment"
- このサイトでしか体験できない瞬間は？
- それはどう作られているか？
- 技術的にどう実現されているか？

### What Makes It Work
- なぜこれが成功しているか
- どんな問題を解決しているか
- 何が他と差別化しているか

### Craft Details
- 見落としがちな細部の工夫
- 404ページ、ローディング、マイクロインタラクション

### What to Learn
- 適用可能な原則
- 避けるべき直接コピー
- 自プロジェクトへの応用
```

### Case Study: Active Theory

```markdown
## 参照分析: Active Theory作品群

### First Impression
- 「これは違う」という即座の認識
- 技術的な驚きと感情的な引き込みが同時
- Level: 確実に5

### Visual System
- 色彩: プロジェクトごとに完全に異なる、クライアントに合わせた世界
- 空間: 没入型、画面全体を体験として使う
- 動き: パフォーマンスを犠牲にしない高品質な動き

### The "Magic Moment"
- インタラクションが「反応」ではなく「会話」
- ユーザーの動きが世界を変える感覚

### What Makes It Work
- 技術力を「見せびらかさない」
- 技術は感情的体験のために存在
- クライアントの本質を視覚化する能力

### Craft Details
- ローディング自体が体験
- トランジションが物語を紡ぐ
- モバイルでも体験が成り立つ工夫

### What to Learn
- 技術を「手段」として扱う姿勢
- すべてのインタラクションに意味を持たせる
- パフォーマンスと美学の両立
```

## Emotional Impact Design

### Impact Points

「印象に残る瞬間」を意図的に設計:

```
Impact Point の配置:

1. Entry Impact (入口の衝撃)
   - Hero の第一印象
   - 3秒以内に世界観を伝える
   - 【Level 5】3秒以内に「これは違う」を確信させる

2. Discovery Moments (発見の瞬間)
   - スクロールで現れる予期しない要素
   - 「これは面白い」と思わせる
   - 【Level 5】探索を報いる隠された喜び

3. Peak Experience (頂点体験)
   - 最も見せたい作品/瞬間
   - すべてがここに収束
   - 【Level 5】息を呑む瞬間

4. Lingering Close (余韻のある終わり)
   - 去る前の最後の印象
   - 記憶に残るclose
   - 【Level 5】また来たいと思わせる
```

### Contrast Creates Memory

```
記憶に残るのは「差」:

- 静けさの中の動き
- 暗闇の中の光
- 抑制の中の解放
- 沈黙の中の声

→ コントラストなき均一は忘れられる

Level 5 のコントラスト:
- 対比が「意味」を持つ
- 対比の「タイミング」が完璧
- 対比が「物語」を語る
```

## Art Direction Quality Checklist

### Award-Worthy Checklist

```
### The "Wow" Test
□ 初見で「これは違う」と感じるか？
□ スクリーンショットを撮りたくなるか？
□ 誰かに見せたくなるか？
□ 何度も訪問したくなるか？

### The "Only Here" Test
□ このサイトでしか体験できない瞬間があるか？
□ コピーが困難な独自性があるか？
□ 見たことのない表現があるか？

### The "Coherence" Test
□ すべての要素が同じ言語を話しているか？
□ 何も浮いていないか？
□ 「なぜこの選択？」にすべて答えられるか？

### The "Craft" Test
□ 404ページまで設計されているか？
□ ローディング状態は美しいか？
□ 最も小さな要素まで意図があるか？
□ スクロールの終端まで配慮されているか？

### The "Emotion" Test
□ 意図した感情が生まれているか？
□ 感情の「変化」があるか？
□ 余韻が残るか？

### The "Innovation" Test
□ 何か新しいことをしているか？
□ 業界に影響を与える可能性があるか？
□ 他のクリエイターが学べる要素があるか？
```

## Anti-Patterns

### Generic Patterns（Level 1-2 に留まる原因）
- **トレンド追従**: 流行りのスタイルを理由なく採用
- **過剰装飾**: 「派手にすれば印象的」という誤解
- **一貫性の欠如**: セクションごとに違う世界観
- **コンセプト不在**: 「なんとなくカッコいい」で進める

### Stagnation Patterns（Level 3-4 に留まる原因）
- **参照なき独創**: 文脈を無視した「オリジナリティ」
- **感情設計の欠如**: 技術先行で感情的インパクトを考えない
- **均一な密度**: 波のないフラットな体験
- **Signature Moment の欠如**: 「ここでしか」の瞬間がない
- **細部の妥協**: 「見えないから」という言い訳
- **予想通りの展開**: 驚きのない、予測可能な体験

## Excellence Reminder

```
Level 5 に到達するために常に問う:

「これは本当に受賞レベルか？」
「他の誰かがこれを見て影響を受けるか？」
「1年後もこれを誇れるか？」
「もっと良くできないか？」

妥協は Level 4 の始まり。
「十分良い」は Level 3 の終わり。
Level 5 は「これ以上は無理」の先にある。
```
