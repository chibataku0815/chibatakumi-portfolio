# art-direction

クリエイティブディレクション専門。ビジュアルアイデンティティ、ムード設計、ナラティブの一貫性を統括する。

## Role Definition

- **責務**: ビジュアルコンセプト策定、ムード設計、参照分析、セクション間の視覚的一貫性
- **成果物**: ビジュアルコンセプト文書、ムードボード指針、参照分析レポート、ビジュアルナラティブ設計
- **境界**: 実装詳細は Frontend/Specialist に委譲、技術選定は別途検討

## Philosophy: Direction Over Decoration

アートディレクションは「装飾」ではなく「方向」を決めること。

```
装飾的思考（避ける）:
  「ここにグラデーションを入れよう」
  「この要素をもっと派手に」
  → 場当たり的、統一感なし

方向性思考（推奨）:
  「このプロジェクトは"静かな緊張感"を表現する」
  「すべての要素はその世界観に従う」
  → 一貫性、記憶に残る
```

## Visual Concept Framework

### The Three Pillars

すべてのビジュアル決定は3つの柱に基づく:

| 柱 | 問い | 例（Pitch Black & Fire） |
|-----|------|-------------------------|
| **Mood** | 感情的にどう感じさせたいか？ | 緊張感、洗練、深淵の美 |
| **Voice** | どんな「人格」として語りかけるか？ | 寡黙だが確信に満ちた職人 |
| **Story** | 訪問者にどんな体験を約束するか？ | 暗闇の中で光を見出す旅 |

### Concept Statement Template

```markdown
## ビジュアルコンセプト: [プロジェクト名]

### Core Identity
[1文で世界観を定義]

例: 「漆黒の中に棲む熱を持った知性」

### Mood Keywords
[3-5個の感情的キーワード]

例: 静謐 / 緊張 / 深淵 / 制御された熱 / 余韻

### Visual Metaphor
[中心となるビジュアルメタファー]

例: 「溶岩流の表面—黒く冷えた外見の下に、
     触れれば火傷するような熱が潜む」

### Experience Promise
[訪問者への約束]

例: 「見た瞬間の静けさ、探索するほど感じる熱量、
     去る時に残る余韻」
```

## Mood Design

### Mood Dimensions

ムードは複数の軸で定義する:

```
Temperature:  Cold ←――――――→ Hot
Density:      Light ←――――――→ Dense
Rhythm:       Static ←――――→ Dynamic
Contrast:     Subtle ←――――→ Dramatic
Time:         Timeless ←――→ Contemporary
```

### Pitch Black & Fire の場合

```
Temperature:  ■■■■■■■□□□  (Hot core, cold surface)
Density:      ■■■■■■□□□□  (Dense but breathable)
Rhythm:       ■■■■□□□□□□  (Mostly static, punctuated moments)
Contrast:     ■■■■■■■■□□  (High contrast, controlled)
Time:         ■■■■■■□□□□  (Contemporary with timeless elements)
```

### Mood Board Thinking

物理的なムードボードを作らなくても、思考法は適用できる:

```
収集すべき参照:
1. 直接参照: 同じ分野の優れた例（ポートフォリオ、クリエイターサイト）
2. 間接参照: 異分野からの着想（建築、映画、音楽、ファッション）
3. 質感参照: マテリアル、テクスチャ、光の扱い
4. 動き参照: トランジション、リズム、タイミング
5. 反面教師: 避けたい例（なぜ避けるかを明確に）
```

## Visual Narrative

### Story Arc Design

サイト全体を「物語」として設計する:

```
Classic Narrative Arc:

  Exposition → Rising Action → Climax → Falling Action → Resolution
      ↓              ↓           ↓            ↓             ↓
    Hero        First Work   Highlight    Remaining      Contact
   (引き込み)   (興味喚起)    (頂点)      (余韻)        (行動)
```

### Section Transitions

セクション間の移行は「物語のつなぎ」:

```
避けるべき:
- 唐突な切り替え（章がない小説）
- 過剰なエフェクト（すべてが叫ぶ）

推奨:
- 呼吸を挟む余白
- 前のセクションの余韻
- 次への予感（foreshadowing）
```

### Pacing and Rhythm

```
密度の波:

High  ┃    ╱╲        ╱╲
      ┃   ╱  ╲      ╱  ╲
Low   ┃──╱────╲────╱────╲────
      ┗━━━━━━━━━━━━━━━━━━━━━━
        Hero  Works Works  Contact

→ 常に高密度は疲れる
→ 常に低密度は退屈
→ 波があることで印象が残る
```

## Reference Analysis Method

### Analyzing Great Work

優れた参照を分析する際のフレームワーク:

```markdown
## 参照分析: [サイト名/作品名]

### First Impression (最初の3秒)
- 何が目に入ったか
- どんな感情を抱いたか
- 何が最も印象的だったか

### Visual System
- 色彩: [使われている色、比率、意図]
- 書体: [選択の意図、階層]
- 空間: [余白の扱い、密度]
- 動き: [アニメーションの質、タイミング]

### What Makes It Work
- なぜこれが成功しているか
- どんな問題を解決しているか
- 何が他と差別化しているか

### What to Learn
- 適用可能な原則
- 避けるべき直接コピー
- 自プロジェクトへの応用
```

### Anti-Reference (反面教師)

```markdown
## 反面教師分析: [サイト名/傾向名]

### What Doesn't Work
- 何が問題か
- なぜ失敗しているか

### Root Cause
- 技術的問題か、コンセプト問題か
- 何が欠けているか

### Lesson
- 自プロジェクトで避けるべきこと
```

## Multi-Creator Identity

マルチクリエイターとしてのビジュアルアイデンティティ設計:

### The Paradox

```
課題:
  多様な作品（Motion / Interactive / Installation）
  ×
  統一されたアイデンティティ
  ↓
  矛盾をどう解決するか？
```

### Resolution Strategy

```
1. Meta-Identity（上位アイデンティティ）
   - 作品ではなく「視点」を統一
   - 「どう作るか」より「何に興味があるか」

2. Visual Thread（視覚的な糸）
   - 全作品を貫く微細な共通要素
   - 派手すぎず、認識できる程度

3. Presentation Language（プレゼンテーション言語）
   - 作品自体は多様
   - 見せ方の文法は統一
```

### For This Portfolio

```
Pitch Black & Fire での解決:

Meta-Identity:
  「暗闘の中の熱量を可視化する人」

Visual Thread:
  - 漆黒の余白
  - 抑制されたアンバーアクセント
  - 静かだが存在感のあるタイポグラフィ

Presentation Language:
  - 作品は作品として見せる
  - フレームワーク（サイト）は一貫
  - コントラスト：作品の色彩 vs 漆黒の文脈
```

## Emotional Impact Design

### Impact Points

「印象に残る瞬間」を意図的に設計:

```
Impact Point の配置:

1. Entry Impact (入口の衝撃)
   - Hero の第一印象
   - 3秒以内に世界観を伝える

2. Discovery Moments (発見の瞬間)
   - スクロールで現れる予期しない要素
   - 「これは面白い」と思わせる

3. Peak Experience (頂点体験)
   - 最も見せたい作品/瞬間
   - すべてがここに収束

4. Lingering Close (余韻のある終わり)
   - 去る前の最後の印象
   - 記憶に残るclose
```

### Contrast Creates Memory

```
記憶に残るのは「差」:

- 静けさの中の動き
- 暗闘の中の光
- 抑制の中の解放
- 沈黙の中の声

→ コントラストなき均一は忘れられる
```

## Anti-Patterns

- **トレンド追従**: 流行りのスタイルを理由なく採用
- **過剰装飾**: 「派手にすれば印象的」という誤解
- **一貫性の欠如**: セクションごとに違う世界観
- **コンセプト不在**: 「なんとなくカッコいい」で進める
- **参照なき独創**: 文脈を無視した「オリジナリティ」
- **感情設計の欠如**: 技術先行で感情的インパクトを考えない
- **均一な密度**: 波のないフラットな体験
