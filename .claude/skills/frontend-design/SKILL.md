# frontend-design

Create distinctive, production-grade frontend interfaces with high design quality. Use this skill when the user asks to build web components, pages, or applications. Generates creative, polished code that avoids generic AI aesthetics.

## Design Thinking

Before writing any code, pause and consider the following:

- **Purpose**: What is this interface trying to achieve? Who is it for?
- **Tone**: Commit to an extreme aesthetic direction. Choose one that fits the context: minimalist, maximalist, retro-futuristic, organic, luxury, playful, brutalist, art deco, or something else entirely.
- **Constraints**: What are the technical requirements? Consider frameworks, performance needs, and accessibility.
- **Differentiation**: What will make this design memorable? What unexpected elements can elevate it beyond the ordinary?

Choose a clear conceptual direction and execute it with precision. Bold maximalism and refined minimalism both work—the key is intentionality, not intensity.

Your implementation should be:

1. **Production-grade**: Code that's ready for real-world use
2. **Visually striking**: Designs that capture attention and create emotional impact
3. **Cohesive**: Every element should feel part of a unified whole
4. **Refined**: Meticulous attention to spacing, alignment, and polish

## Frontend Aesthetics Guidelines

### Typography

Typography is the backbone of frontend design. Make distinctive choices that elevate the interface's aesthetics.

- Avoid generic font stacks like Arial, Helvetica, or Inter without intentional purpose
- Consider pairing a distinctive display font with a complementary body font
- Pay attention to line height, letter spacing, and font weights
- Use typography as a design element, not just for content

### Color & Theme

Commit to a cohesive color aesthetic. Use CSS variables for consistency.

- Dominant colors with sharp accents outperform timid, safe palettes
- Consider the psychological and cultural implications of your color choices
- Dark themes, light themes, and unusual palettes all work when executed with intention
- Don't default to gradients unless they serve the design concept

### Motion & Animation

Motion should be purposeful and enhance the user experience.

- Prioritize CSS animations for HTML elements; use JavaScript animation libraries for complex sequences
- Focus on high-impact moments: page loads with orchestrated staggered reveals, meaningful hover states, smooth transitions
- Avoid scattered micro-interactions that distract rather than enhance
- Consider timing, easing, and choreography as carefully as visual design

### Spatial Composition

Break free from predictable layouts.

- Employ unexpected layouts, asymmetry, and overlap
- Use diagonal flow and grid-breaking elements when appropriate
- Consider negative space as a design element
- Layer elements to create depth and visual interest

### Backgrounds & Details

Create atmosphere through intentional background and decorative choices.

- Consider gradient meshes, noise textures, geometric patterns
- Use layered transparency, dramatic shadows, decorative borders
- Custom cursors, grain overlays, and contextual visual effects can elevate the experience
- Backgrounds should support, not compete with, content

## What to Avoid

Never produce generic AI-generated aesthetics. Common patterns to avoid:

- **Overused fonts**: Inter, Roboto, Arial as default choices without intention
- **Clichéd color schemes**: Purple/blue gradients on white backgrounds
- **Predictable layouts**: Centered content with uniform spacing
- **Missing context**: Designs that could belong to any product or brand
- **Safe choices**: Middle-ground decisions that neither excite nor offend

## Implementation Philosophy

Match implementation complexity to the aesthetic vision:

- **Maximal designs** need elaborate code with extensive animations, layered effects, and rich interactions
- **Minimal or refined designs** need restraint, precision, and careful attention to spacing, typography, and subtle details

The goal is not complexity for its own sake, but rather the appropriate level of implementation detail to realize the design vision fully.
