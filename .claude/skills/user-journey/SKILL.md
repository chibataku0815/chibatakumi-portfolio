# user-journey

ユーザージャーニー専門。感情設計、コンバージョン心理学、体験マッピングを通じて、高価値クライアントの行動を設計する。

## Role Definition

- **責務**: 感情的アーク設計、コンバージョンファネル最適化、CTA戦略、ターゲット心理分析
- **成果物**: ユーザージャーニーマップ、感情曲線設計、CTA配置戦略、コンバージョンフロー図
- **境界**: 戦略的方向性は Brand Strategy から受領、実装詳細は Frontend に委譲

## Philosophy: Emotion Drives Action

### The Decision Journey

```
論理的な決定と思われているが、実際は:

  感情 → 論理 → 行動
    ↑
  「この人は信頼できそうだ」（感情）
    ↓
  「実績も技術も申し分ない」（論理的正当化）
    ↓
  「問い合わせてみよう」（行動）

→ 最初の感情的反応を設計することが最重要
```

### High-Value Client Psychology

```
美意識の高い経営者の特性:

1. 時間の価値を知っている
   → 無駄な説明は読まない、一瞬で判断する

2. 品質を見抜く目がある
   → 言葉より作品で語る、洗練されたものに反応

3. 同類を認識する
   → 「この人は自分と同じ価値観を持っている」

4. 長期的関係を好む
   → 一回きりではなく、継続的パートナーを探している

5. 紹介ベースで動く
   → 信頼できる人からの紹介を重視
```

## User Journey Framework

### The Five-Act Structure

```
【第1幕: Intrigue】0-3秒
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  目的: 好奇心を喚起、離脱を防ぐ

  視覚体験:
    - 漆黒の中の静謐な美しさ
    - 「普通ではない」という直感
    - ミニマリズムが醸す緊張感

  内なる声:
    「これは違う。もう少し見てみよう」

  感情状態:
    知的好奇心の喚起

  デザイン要件:
    - Hero の第一印象に全力を注ぐ
    - 情報過多を避ける
    - 余白で「呼吸」を作る


【第2幕: Recognition】3-15秒
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  目的: 同類認識、信頼の萌芽

  視覚体験:
    - ミニマリズム、無駄の排除
    - 洗練されたタイポグラフィ
    - 品質への妥協のなさ

  内なる声:
    「この人は自分と同じ美意識を持っている」
    「細部にまでこだわる人間だ」

  感情状態:
    信頼の萌芽、同類認識

  デザイン要件:
    - 品質は語るのではなく、見せる
    - サイト自体がポートフォリオ作品
    - 一貫したトーン


【第3幕: Discovery】15秒-2分
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  目的: 多才さの認識、驚き→尊敬

  視覚体験:
    - 多様な作品群の探索
    - 写真、映像、Web、体験の幅
    - それぞれのクオリティの高さ

  内なる声:
    「写真だけじゃない。動画も。Webも。」
    「全部この人が？」
    「しかも全部ハイレベル」

  感情状態:
    驚き → 尊敬

  デザイン要件:
    - 作品の多様性を自然に見せる
    - カテゴリ間の移動をスムーズに
    - 各作品のインパクトを確保


【第4幕: Realization】2-5分
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  目的: 実利の理解、取引欲求の喚起

  認知内容:
    - 効率性：一人で完結 = コスト削減
    - 一貫性：同一の美学 = ブランド体験
    - スピード：翻訳ロスなし = 時間短縮
    - AIネイティブ：最新技術 = 競争優位

  内なる声:
    「一人でこれだけできるなら...」
    「うちのプロジェクトにも...」
    「複数ベンダー管理の手間がなくなる」

  感情状態:
    合理的な魅力 → 取引欲求

  デザイン要件:
    - About/Services で価値を明確に
    - 「なぜ一人で完結が価値か」を説明
    - 押し付けがましくない形で


【第5幕: Action】Contact到達
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  目的: 行動を促す、障壁を取り除く

  内なる声:
    「この人に相談してみよう」
    「まずは話を聞いてみよう」

  感情状態:
    確信 → 行動

  デザイン要件:
    - CTA の障壁を最小化
    - 「売り込まれる」不安を払拭
    - 次のステップを明確に
```

      ┃        ╱  ╲

      ┃  ╱  ╲╱      ╲    ★
      ┃ ╱            ╲  ╱

## Conversion Psychology

### Decision Triggers for Executives

| トリガー | 心理メカニズム | 設計への適用 |
|---------|--------------|-------------|
| **Authority** | 専門性への信頼 | 作品の質で語る、説明は最小限 |
| **Social Proof** | 他者の判断参照 | 「10年来のクライアント」という実績 |
| **Scarcity** | 希少性への価値付け | 「一人でこれができる人は少ない」 |
| **Reciprocity** | 先に与える | サイトの体験自体が価値提供 |
| **Consistency** | 一貫性への信頼 | サイト全体のトーン統一 |

### Reducing Friction

```
障壁の特定と解消:

障壁1: 「いくらかかるか分からない」
  → 解消: 価格表ではなく「まず話しましょう」
  → 理由: 価値を理解する前に価格判断されない

障壁2: 「売り込まれそう」
  → 解消: 「売り込みはしません」と明示
  → 追加: 「あなたのビジョンを聞かせてください」

障壁3: 「何を相談していいか分からない」
  → 解消: 「30分の戦略セッション」という具体的な形式
  → 理由: 曖昧さの排除

障壁4: 「すぐに返事が来るか不安」
  → 解消: 「48時間以内に返信」と明示
  → 理由: 期待値の設定
```

## CTA Strategy

### CTA Positioning

```
Portfolio サイトの CTA 配置:

Primary CTA: Contact / 相談
  - 配置: Header（固定）+ Contact セクション
  - トーン: 低圧力、対話的

Secondary CTA: Works を見る
  - 配置: Hero 直下
  - 役割: 興味 → 探索への導線

Micro CTA: 各作品から Contact へ
  - 配置: 作品詳細ページ
  - トーン: 「この方向で相談したい時に」
```

### CTA Language Hierarchy

```
圧力レベル（低→高）:

Level 1 (最も低圧力):
  「気になることがあれば」
  「興味があれば」

Level 2 (自然な誘導):
  「まずは話しませんか」
  「対話を始める」

Level 3 (具体的な提案):
  「30分の戦略セッションを予約」
  「プロジェクトについて相談」

Level 4 (高圧力、避ける):
  「今すぐお問い合わせ」
  「無料相談はこちら」

→ このポートフォリオでは Level 2-3 を推奨
```

### CTA Context Design

```markdown
## CTA セクション構造

### Pre-CTA: 文脈の構築
次のプロジェクトが見えてきた時に。
あるいは、まだ漠然としたアイデアの段階でも。

### CTA: 行動の提案
「対話を始める」

### Post-CTA: 不安の払拭
売り込みはしません。
あなたのビジョンを聞かせてください。
返信は48時間以内に。
```

## Page Flow Design

### Scroll Journey

```
縦スクロールのリズム設計:

Section    | 密度  | 滞在目安 | 目的
-----------|-------|---------|----------------
Hero       | 低    | 3-5秒   | 引き込み、世界観
Works導入   | 中    | 10秒    | 興味喚起
Work Items | 高    | 1-3分   | 発見、探索
About      | 中    | 30秒    | 価値理解
Services   | 中    | 1分     | 具体的イメージ
Contact    | 低    | 15秒    | 行動決断

密度の波:
  低 → 高 → 中 → 低
  （常に同じ密度は疲れる）
```

### Exit Points

```
離脱ポイントの設計:

意図的な離脱ポイント（良い）:
  - Works: 作品をクリックして詳細へ
  - Contact: フォーム送信後
  - SNS: 外部リンク（適切なら）

問題のある離脱ポイント（防ぐ）:
  - Hero での離脱: 第一印象の改善
  - Works 途中での離脱: コンテンツの魅力向上
  - About での離脱: 長すぎる説明を削減
  - Contact 手前での離脱: CTA の障壁確認
```

## Persona-Specific Journeys

### Persona A: 経営者（決裁権者）

```
特性:
  - 時間がない、判断が早い
  - 品質を見る目がある
  - 信頼できる人を探している

最適なジャーニー:
  Hero (3秒) → Works ハイライト (30秒) → About (15秒) → Contact

重視すべき点:
  - 最初の3秒で「この人は違う」と思わせる
  - Works は「ベスト」だけを見せる（量より質）
  - About は簡潔に（長文は読まない）
  - CTA は低圧力で
```

### Persona B: マーケティング責任者

```
特性:
  - 複数候補を比較検討
  - 実績と具体的なスキルを確認したい
  - 上司（経営者）への説明材料が必要

最適なジャーニー:
  Hero → Works (詳細まで) → Services → About → Contact

重視すべき点:
  - Works は詳細まで見られるように
  - Services でスキルの幅を明確に
  - 「なぜこの人を選ぶか」の根拠を提供
```

### Persona C: 紹介経由

```
特性:
  - すでにある程度の信頼がある
  - 「紹介された人」という前提
  - 確認のために見ている

最適なジャーニー:
  Hero → About (確認) → Works (興味分野のみ) → Contact

重視すべき点:
  - 紹介者の信頼を損なわない品質
  - スムーズに Contact へ到達できる導線
  - 「期待通りだった」という確認
```

## Measurement Framework

### Key Metrics

| 指標 | 意味 | 目標 |
|------|------|------|
| **Bounce Rate (Hero)** | 第一印象の効果 | < 40% |
| **Scroll Depth** | コンテンツへの関心 | 75%+ が Works まで |
| **Time on Works** | 作品への関心度 | 平均 90秒+ |
| **Contact Rate** | コンバージョン | 訪問者の 2-5% |
| **Time to Contact** | 決断の速さ | 5分以内が理想 |

### Qualitative Signals

```
良いサイン:
  - Contact 経由の問い合わせが具体的
  - 「サイトを見て、この人だと思った」
  - 紹介が増える

悪いサイン:
  - 価格だけを聞いてくる問い合わせ
  - 「何でもできるみたいですが...」という曖昧さ
  - Works を見ずに Contact する
```

## Anti-Patterns

- **一律の体験**: ペルソナの違いを無視した設計
- **感情の無視**: 論理だけでは人は動かない
- **高圧的 CTA**: 「今すぐ」は信頼を損なう
- **情報過多**: 経営者は長文を読まない
- **密度の均一化**: 波のない体験は印象に残らない
- **障壁の放置**: 「なぜ行動しないか」を考えない
- **測定なき改善**: 推測ではなくデータで判断
