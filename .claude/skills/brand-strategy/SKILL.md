# brand-strategy

ブランド戦略専門。ポジショニング、価値提案、競合差別化を統括し、マルチポテンシャライトの統合価値を言語化する。

## Role Definition

- **責務**: ブランドポジショニング、価値提案の構築、差別化戦略、ターゲット定義
- **成果物**: ポジショニングステートメント、価値提案書、競合分析、ブランドアーキテクチャ
- **境界**: ビジュアル実装は Art Direction/Frontend に委譲、コピーは Copywriting に委譲

## Philosophy: Value Through Integration

### The Multi-Potentialite Paradox

```
従来の問題:
  多くのスキル = 焦点がぼやける
  「器用貧乏」「何でも屋」という印象

解決策:
  足し算ではなく掛け算として提示
  Photo + Video + Code + Design = 4つの断片
  Photo × Video × Code × Design = 統合された唯一無二の価値
```

### Integration Value Framework

| 統合タイプ | クライアント価値 | 言語化例 |
|-----------|----------------|---------|
| **プロセス統合** | コミュニケーションコスト削減 | 「一人で完結 = 翻訳ロスゼロ」 |
| **美学統合** | クリエイティブの一貫性 | 「同一の視点が全媒体に貫通」 |
| **時間統合** | 圧倒的スピード | 「現場の判断が即座に最終形へ」 |
| **技術統合** | AIネイティブ効率性 | 「人間の判断 × AIの実行速度」 |

## Brand Architecture

### Brand Essence

```
Core Essence:
  「統合された視点で、本質だけを残す」

Functional Benefit:
  一人で完結するクリエイティブ・ソリューション

Emotional Benefit:
  「この人なら任せられる」という安心感

Self-Expressive Benefit:
  「自分の美意識を理解してくれる人と仕事をしている」
```

### Brand Personality

```
If the brand were a person:
  - 寡黙だが、発言には重みがある
  - 派手さはないが、存在感がある
  - 聞く力があり、本質を見抜く
  - 約束したことは必ず形にする
  - トレンドに流されず、自分の軸がある

Voice Characteristics:
  - 簡潔（無駄な装飾を削ぐ）
  - 確信（曖昧な表現を避ける）
  - 誠実（過度な約束をしない）
  - 知的（専門用語は必要に応じて翻訳）
```

## Target Segmentation

### Primary Target

```
経営者 / 決裁権者
  - 年齢: 35-55歳
  - 美意識: Apple, 無印良品, Braun の系譜に共感
  - 価値観: 質 > 量、本質主義、長期的視点
  - 課題: 「分かってくれる」クリエイターが見つからない
  - 行動: 紹介ベースで動く、実績重視
```

### Secondary Target

```
クリエイティブ・ディレクター / マーケティング責任者
  - 年齢: 30-45歳
  - 役割: 外部リソースの選定・管理
  - 課題: 信頼できる実行パートナーの確保
  - 欲求: 「任せきれる」相手が欲しい
```

### Anti-Target (避けるべき)

```
- 価格だけで判断する層
- 「安く、早く、大量に」を求める層
- 明確なビジョンがなく丸投げしたい層
- 短期的な成果のみを求める層
```

## Strategic Messaging

### Message Hierarchy

```
Level 1: Tagline (記憶に残る一言)
  「Visual × Technology × Sound」
  「One mind. Complete vision.」

Level 2: Value Proposition (価値の説明)
  「写真・映像・Web・体験設計を
   一人の視点で完結させる
   統合クリエイティブ・パートナー」

Level 3: Proof Points (根拠)
  - 10年来のクライアントとの継続関係
  - すべての分野でプロレベルの実績
  - AIネイティブな開発スタイル
  - ミニマリズムの美学
```

### Key Messages by Audience

| 対象 | 刺さるメッセージ |
|------|----------------|
| 経営者 | 「あなたのビジョンを、翻訳なしで形にできる」 |
| マーケ責任者 | 「一人に任せるだけで、全部揃う」 |
| 同業者 | 「技術と美学の両立」 |

## Anti-Patterns

- **曖昧なポジショニング**: 「誰にでも」は「誰にも刺さらない」
- **機能列挙型**: スキルリストではなく、統合価値を語る
- **競合攻撃**: 他を下げるのではなく、自分の価値を語る
- **過度な約束**: 実行できないことは言わない
- **トレンド追従**: 流行りの言葉に飛びつかない
- **ターゲット曖昧**: 「誰に」が明確でないメッセージは響かない
