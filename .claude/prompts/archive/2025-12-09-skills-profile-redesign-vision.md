# Skills & Profile Page Redesign Vision

**Art Direction × Motion Design × Visual Composition 統合設計書**

---

## 0. 現状の根本的問題

### 現在のアプローチの限界

```
現状（Skills/Profile共通）:
┌─────────────────────────────────────────┐
│                                         │
│  [Label]  [Title]  [Tags]               │  ← すべて同じリズム
│                                         │
│  [Description]                          │  ← すべて同じ配置
│                                         │
│  [Tags] [Tags] [Tags]                   │  ← すべて同じ密度
│                                         │
└─────────────────────────────────────────┘
× セクションごとに同じレイアウト
× 予測可能で退屈
× 情報の「陳列」であって「体験」ではない
× アニメーションが「効果」であって「意味」ではない
```

### 受賞サイトとの決定的な差

| 要素 | 現状 | 受賞サイトレベル |
|------|------|------------------|
| **構図** | 中央寄り、均等配置 | 非対称、意図的な緊張 |
| **視線誘導** | なし（要素を置いただけ） | 明確なフロー設計 |
| **余白** | 受動的（たまたま空いた） | 能動的（意図的な深淵） |
| **モーション** | 汎用reveal（fade/slide） | 意味を運ぶ動き |
| **ストーリー** | なし | 各セクションが物語の一章 |

## 1. Art Direction: ビジュアルコンセプト再定義

### Core Identity

> **「漆黒の深淵に棲む、統合された熱量」**

Skills/Profileは「情報ページ」ではなく「体験の章」。
訪問者が「この人は本物だ」と確信する瞬間を設計する。

### Mood Keywords

```
静謐 / 深淵 / 確信 / 熱量 / 余韻
```

### Visual Metaphor

```
Skills Page:
  「水面下の氷山」
  - 見えている部分（Title）は一部
  - 本当の広がりは探索して初めてわかる
  - スキル同士が水面下でつながっている

Profile Page:
  「地層」
  - 時間の堆積（Timeline）
  - 深く掘るほど豊かな発見
  - 各層が現在の自分を形成している
```

### Emotional Arc（感情の設計）

```
Skills Page:
  Entry: 「多才だな」(curiosity)
    ↓
  Mid: 「これも？これも？」(surprise)
    ↓
  Peak: 「全部繋がってる」(realization)
    ↓
  Exit: 「一人でここまで」(respect)

Profile Page:
  Entry: 「経験を見てみよう」(neutral)
    ↓
  Mid: 「深い」(engagement)
    ↓
  Peak: 「この人の視点は一貫している」(trust)
    ↓
  Exit: 「任せたい」(action intent)
```

## 2. Visual Composition: 構図の再設計

### Grid System

現状の問題:
```
┌────────────────────────────────────┐
│  ┌──────────────────────────────┐  │
│  │     中央寄りの均等配置        │  │
│  │     (退屈、予測可能)          │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

提案: **非対称 + ダイナミックグリッド**
```
Skills Section 1:
┌────────────────────────────────────────┐
│                          ┌───────────┐ │
│  ┌─────────────────┐     │   PHOTO   │ │
│  │     VIS         │     │   (large) │ │
│  │    ●━━━━━━━━━━━━│━━━━━│           │ │
│  │  [Title]        │     │           │ │
│  │                 │     └───────────┘ │
│  │  [Description]  │                   │
│  │                 │     [Tags]        │
│  └─────────────────┘     [Tags]        │
│                                        │
└────────────────────────────────────────┘

Skills Section 2: (構図を変える)
┌────────────────────────────────────────┐
│ ┌───────────┐                          │
│ │   FILM    │     ┌─────────────────┐  │
│ │   (large) │     │     FIL         │  │
│ │           │━━━━━│●                │  │
│ │           │     │  [Title]        │  │
│ └───────────┘     │                 │  │
│                   │  [Description]  │  │
│     [Tags]        │                 │  │
│     [Tags]        └─────────────────┘  │
└────────────────────────────────────────┘

→ セクションごとに構図が変わる
→ 予測不能 = 探索の喜び
```

### Visual Flow Design

```
Skills Page 視線フロー:

     ╭──────────────────────────────────╮
     │                                  │
     │  ① Ghost Text (VIS)             │
     │        ↘                        │
     │           ② Title               │
     │               ↓                 │
     │           ③ Description         │
     │               ↓                 │
     │           ④ Skill Image ←────┐  │
     │                              │  │
     │  ⑤ Tags ─────────────────────┘  │
     │        ↓                        │
     │  ⑥ Transition Line              │
     │        ↓                        │
     │  [Next Section]                 │
     ╰──────────────────────────────────╯

→ 視線が「流れる」設計
→ 各要素に到達する順序が意図的
```

### Negative Space Strategy

```
現状:
  Element : Space = 1 : 0.8  (詰め込み気味)

提案:
  Element : Space = 1 : 2.5  (贅沢な余白)

余白の意味:
┌────────────────────────────────────────┐
│                                        │
│                                        │  ← この余白は「深淵」
│                                        │     漆黒が呼吸する空間
│         [Title]                        │
│                                        │
│                     [Description]      │  ← 非対称配置で緊張
│                                        │
│                                        │
└────────────────────────────────────────┘
```

### Tension Creation

```
緊張を生む配置:

1. Edge Proximity (端への接近)
   ┌──────────────────┐
   │                  │
   │            [VIS]─│ ← Ghost が端にはみ出す
   │                  │
   └──────────────────┘

2. Scale Contrast (スケール対比)
   ┌──────────────────┐
   │                  │
   │ ██████████████   │ ← 巨大なGhost
   │        •         │ ← 小さいアクセント
   └──────────────────┘

3. Diagonal Placement (斜め配置)
   ┌──────────────────┐
   │ [A]              │
   │      ╲          │
   │        ╲ [B]    │
   │           ╲     │
   │             [C] │
   └──────────────────┘
```

## 3. Motion Design: アニメーションの意味設計

### Philosophy Shift

```
現状:
  「要素を出現させる」ための動き
  → fade-in, slide-up の羅列
  → 意味がない、記憶に残らない

提案:
  「意味を伝える」ための動き
  → 各動きが感情を運ぶ
  → 一貫した性格を持つ
```

### Motion Personality

```
Skills/Profile の動きの性格:

「静かな確信」
- 急がない（慌てていない = 自信）
- 過剰に主張しない（品格）
- しかし存在感がある（力強さ）
- 終わった後に余韻がある（深み）
```

### Entry Animation Redesign

**現状の問題:**
```
すべての要素が同じタイミングで fade-in
→ 「何も言っていない」に等しい
```

**提案: Choreographed Reveal (振り付けされた出現)**

```
Skills Section Entry Timeline:

T+0.0s  ────────────────────────────────
        │
        │  [背景: 漆黒から微かなグラデーションへ]
        │  Mood: 「何かが始まる」
        │
T+0.3s  ────────────────────────────────
        │
        │  [Ghost Text: 深淵から浮かび上がる]
        │  - blur(12px) → blur(0)
        │  - y: 80 → 0
        │  - opacity: 0 → 0.15
        │  - scale: 1.1 → 1.0
        │  Duration: 1.2s
        │  Ease: expo.out
        │  Mood: 「存在の予感」
        │
T+0.6s  ────────────────────────────────
        │
        │  [Rail: 上から下へ reveal]
        │  - clipPath: inset(0 0 100% 0) → inset(0)
        │  Duration: 1.0s
        │  Ease: expo.out
        │  Mood: 「構造の出現」
        │
T+0.9s  ────────────────────────────────
        │
        │  [Title Band: 左からスライド + 影の出現]
        │  - x: -120% → 0%
        │  - boxShadow: 0 0 0 → 14px 14px 0
        │  Duration: 0.9s
        │  Ease: expo.out
        │  Mood: 「主題の提示」
        │
T+1.2s  ────────────────────────────────
        │
        │  [Description: 文字単位でタイプライター的reveal]
        │  - 1文字ずつ opacity: 0 → 1
        │  - blur(4px) → blur(0)
        │  Stagger: 0.008s/char
        │  Mood: 「語り始める」
        │
T+1.8s  ────────────────────────────────
        │
        │  [Tags: ピアノの鍵盤を叩くようにstagger]
        │  - y: 20 → 0
        │  - opacity: 0 → 1
        │  Stagger: 0.08s (速めのリズム)
        │  Ease: power3.out
        │  Mood: 「技術の羅列ではなく、音楽」
        │
T+2.2s  ────────────────────────────────
        │
        │  [Skill Image: mask reveal + parallax開始]
        │  - clipPath: circle(0% at center) → circle(100%)
        │  Duration: 1.0s
        │  Ease: expo.out
        │  Mood: 「視覚的証拠の提示」
        │
T+2.5s  ────────────────────────────────
        │
        │  [すべての要素が揃った状態]
        │  [parallax が継続的に動作]
        │
────────────────────────────────────────
```

### Scroll-Driven Parallax Redesign

**現状の問題:**
```
Ghost: y移動のみ
→ 単調、意味がない
```

**提案: Multi-layer Parallax**

```
Layer Architecture:

L4 (最前面): UI / Progress
    ↑ 動かない (固定)

L3: Primary Content (Title, Description)
    ↑ scroll * 0.1 (微細な追従)

L2: Accent Elements (Tags, Lines)
    ↑ scroll * 0.3 (中程度の追従)

L1: Ghost Text
    ↑ scroll * 0.6 (大きな追従)
    ↑ + scale: 1 → 0.9 (遠ざかる感覚)
    ↑ + opacity: 0.15 → 0.08 (薄れていく)

L0: Background (Shader)
    ↑ scroll * 1.2 (オーバースクロール)
    → 前面より速く動く = 深みの錯覚

視覚効果:
  スクロールすると Ghost が「沈んでいく」
  → Skills の深さを視覚的に表現
```

### Transition Between Sections

**現状の問題:**
```
セクション間: 単なるスクロール
→ 「章」の区切りがない
```

**提案: Narrative Transitions**

```
Section A → Section B:

1. Section A の終わり
   - Tags が下へ fade out
   - Ghost が完全に沈む
   - 「章の終わり」の余韻

2. Transition Zone (50vh)
   - 漆黒の余白
   - 次の Ghost が深淵から浮上し始める
   - 「次への予感」

3. Section B の始まり
   - 新しい構図で Ghost が position へ
   - 新しいストーリーの開始

Timeline:
  ●────────○────────────────●────────○
  A終わり  余白        B始まり  B展開
          (呼吸)
```

### Micro-Interactions

```
Tags Hover:
  - scale: 1 → 1.05
  - backgroundColor: white/8 → white/14
  - translateY: 0 → -3px
  - boxShadow: none → 0 4px 12px rgba(0,0,0,0.3)
  Duration: 200ms
  Ease: power2.out

  → 「触れられる」感覚

Skill Image Hover:
  - scale: 1 → 1.02
  - filter: none → brightness(1.1)
  - cursor: zoom-in
  Duration: 300ms

  → 「もっと見たい」を誘発
```

## 6. Implementation Priority

### Phase 1: Foundation (基盤)

```
1. 構図パターンの CSS Grid 実装
   - Pattern A/B/C の 3パターン
   - レスポンシブ対応

2. Ghost Text の刷新
   - フルワード + オーバーフロー
   - mix-blend-mode: overlay

3. 余白の拡大
   - Element:Space = 1:2.5
   - セクション間に余白ゾーン追加
```

### Phase 2: Motion (動き)

```
1. Entry Animation の振り付け
   - タイムライン設計の実装
   - 各要素の意味ある出現

2. Multi-layer Parallax
   - 4層のレイヤー管理
   - 各層の速度差設定

3. Section Transitions
   - 呼吸の間
   - 次への予感
```

### Phase 3: Polish (磨き)

```
1. Micro-interactions
   - Tags hover
   - Image hover

2. Kinetic Typography
   - Description の文字単位 reveal

3. Performance Optimization
   - will-change 管理
   - requestAnimationFrame 使用
```

## 7. 禁止事項（絶対に避けること）

```
【コミット禁止】
git commit は絶対に実行しない

【動きの禁止事項】
- back.out, bounce 系 ease（安っぽい）
- 同時多発的な動き（カオス）
- 意味のない動き（装飾のため）

【レイアウトの禁止事項】
- すべて中央配置（退屈）
- 均等分割（思考停止）
- 余白恐怖症（詰め込み）

【技術的禁止事項】
- backgroundPositionY（reflow）
- layout を動かすプロパティ
- filter の乱用（パフォーマンス）
```

## 8. 成功の指標

```
視覚的指標:
□ 各セクションを見た瞬間「違う」と感じるか
□ スクロールに意味があるか（単なる移動でなく）
□ 余白が「深淵」として機能しているか
□ Ghost Text が空間の奥行きを作っているか

感情的指標:
□ Skills: 「この人は本物」と思えるか
□ Profile: 「信頼できる」と感じるか
□ 全体: 「覚えている」と言えるか

技術的指標:
□ 60fps 維持
□ LCP 2.5s 以下
□ CLS 0.1 以下
```
