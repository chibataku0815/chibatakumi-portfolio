## 参考メモ

- Tailwind CSS v4は、旧バージョンと比較して設定方法が大きく変わっている
- PostCSSプラグインが別パッケージに移動したことに注意
- CSS-first configurationのアプローチを理解し活用する
- 新しいConcurrent Mode対応の高速エンジンの恩恵を受けるため、開発フローを最適化する
